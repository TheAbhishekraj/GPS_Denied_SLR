TITLE: Image Matching-Based Visual-Inertial Integrated Navigation for UAV in GNSS-Denied Environments
AUTHORS: Huang T.; Zhou Y.; Zhang B.
YEAR: 2024.0
ABSTRACT: For unmanned aerial vehicle (UAV) navigation in global satellite navigation system (GNSS)-denied environments, an image matching-based visual-inertial integrated navigation system is proposed. Deep learning-based methods are used for image matching to address the challenges of multi-modal image matching. A feature mismatch removal method using reference visual data and inertial navigation prior pose is proposed to improve the accuracy and robustness of image matching. Error-state Kalman filtering (ESKF) is applied to fuse the outputs of visual navigation and inertial navigation and calibrate the inertial navigation system. In addition, an image mismatch detection method based on Kalman innovation detection is applied to avoid severe errors caused by image mismatch. Finally, the proposed integrated navigation system is validated by Airsim simulation and a public dataset.  © Published under licence by IOP Publishing Ltd.
