TITLE: Autonomous Museum Assistance Robot: Enhancing Visitor Navigation with Real-Time Localization
AUTHORS: M. M. Vaishnavi; G. Barath; V. R. Barun; A. Abisek; N. Karthikeyan
YEAR: 2025
ABSTRACT: This paper presents the design and implementation of an autonomous museum assistance robot that guides visitors to exhibits using RFID-based localization and a touchscreen-based selection interface. The robot employs an ESP32 microcontroller for processing user input and computing the shortest path based on predefined routes marked with RFID tags. Users interact with the robot through a web-based UI hosted over Wi-Fi, allowing destination selection and receiving real-time position updates. The robot dynamically localizes itself using RFID checkpoints and provides the information in the web-based UI upon reaching exhibits. This approach improves accessibility for visitors with mobility issues and enhances the overall user experience in cultural environments. Future enhancements such as AI-based dynamic path optimization and obstacle avoidance are also discussed.
