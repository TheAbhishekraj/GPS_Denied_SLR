TITLE: Real-Time Detection of Mine-Like Objects for Semantic-Guided Underwater Robot Navigation
AUTHORS: V. Sineglazov; M. Savchenko
YEAR: 2025
ABSTRACT: Semantic-guided underwater navigation requires advanced object recognition systems that enable autonomous vehicles to make intelligent routing decisions instead of relying on basic collision avoidance. Maritime operations in mine-contaminated waters require navigation algorithms capable of treating detected mine-like objects as both hazards to avoid and as navigational references for positioning. Underwater environments complicate reliable target identification through signal degradation, reflections, and scattering that make distinct object types acoustically indistinguishable. Processing side-scan sonar data introduces more difficulties as mine-like contacts demonstrate significant similarity to harmless seafloor debris, natural formations, and man-made clutter, compounded by environmental degradation processes including biological encrustation and material deterioration, that modify target appearance. Successful implementation of such object recognition technology requires balancing high target detection rates against minimal false classifications, since navigation errors from misidentified objects negatively impact autonomous path planning effectiveness. This study proposes a methodology for real-time detection and classification of mine-like objects from side-scan sonar images by augmenting RT-DETR architecture with deformable convolutional blocks and SIoU loss function to address the geometric complexities and precise localization requirements of similar mine-like contacts and man-made clutter underwater. Experimental validation on a side-scan sonar image collection demonstrates that the proposed approach achieves 4.6% improvement in mean average precision, 3.1% improvement in precision, and 4.3% improvement in recall compared to baseline model, while maintaining real-time operational capability for autonomous underwater navigation.
