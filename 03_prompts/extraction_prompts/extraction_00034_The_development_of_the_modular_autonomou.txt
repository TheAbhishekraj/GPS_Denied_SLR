ABSTRACT: This paper addresses the design method of navigation system for the autonomous underwater vehicle (AUV), which includes overall navigation architecture, hardware and software structure. The autonomous underwater navigation system consists of many software, hardware components and the systematic integration of these components is very important to build up the efficient navigation system within the given resources.
