TITLE: Drone Positioning in a Specified Location Using Visual Data Under GPS-denied Conditions

YEAR: 2025
VENUE: NOT_IN_ABSTRACT
DOI: 10.1109/IDAACS68557.2025.11322385
ABSTRACT: In Global Positioning System (GPS)-denied environments where standard positioning systems fail due to interference or jamming, drones face difficulty in maintaining a stable position using only inertial sensors like gyroscopes and accelerometers. These sensors accumulate drift over time, making position estimates increasingly unreliable. This work proposes a vision-based method to compensate for inertial drift by analyzing images captured from a downward-facing camera. The algorithm detects key points using ORB and estimates the drone’s displacement through homograph computation. This approach enables real-time correction of position and orientation, offering a reliable solution for fixed-position hovering.
