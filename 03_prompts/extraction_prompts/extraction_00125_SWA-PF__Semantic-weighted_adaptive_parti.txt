TITLE: SWA-PF: Semantic-weighted adaptive particle filter for memory-efficient 4-DoF UAV localization in GNSS-denied environments
AUTHORS: Yuan J.; Dai M.; Zheng E.; Su C.; Chen N.; Hu Q.; Zhu S.; Cao Y.
YEAR: 2026
VENUE: Pattern Recognition
DOI: 10.1016/j.patcog.2026.114522
ABSTRACT: Vision-based Unmanned Aerial Vehicle (UAV) localization systems have been extensively investigated for Global Navigation Satellite System (GNSS)-denied environments. However, existing retrieval-based approaches face limitations in dataset availability and persistent challenges including suboptimal real-time performance, memory inefficiency for onboard deployment, environmental sensitivity, and limited generalization capability, particularly in dynamic or temporally varying environments. To overcome these limitations, we present a large-scale Multi-Altitude Flight Segments dataset (MAFS) for variable altitude scenarios and propose a novel Semantic-Weighted Adaptive Particle Filter (SWA-PF) method. This approach integrates robust semantic features from both UAV-captured images and satellite imagery through three core innovations: a compact 4-DoF particle representation with strictly linear memory complexity, a semantic weighting mechanism, and an optimized particle filtering architecture. The compact particle design achieves negligible per-particle memory overhead, enabling memory-efficient deployment on resource-constrained UAV onboard computing platforms. Evaluated using our dataset, the proposed method achieves approximately 10× end-to-end computational efficiency gain over classical feature-based methods when embedded in the same particle filter localization framework, maintains global positioning errors below 10 meters with respect to onboard GNSS-based pose measurements, and enables rapid 4 degree of freedom (4-DoF) pose estimation within seconds using accessible low-resolution satellite maps. Code and dataset will be available at https://github.com/YuanJiayuuu/SWA-PF. © 2026 Elsevier Ltd
