TITLE: Autonomous Navigation of a Single UAV in Cluttered Indoor Environment via Cuckoo Search Algorithm
AUTHORS: D. H. Burande; S. C. Kulkarni; N. L. Bhirud; I. Swain; A. M. Ekatpure; S. Agrawal
YEAR: 2025
VENUE: NOT_IN_ABSTRACT
DOI: 10.1109/ICEC2NT65402.2025.11380007
ABSTRACT: The paper introduces an optimized path planning strategy for a single Unmanned Aerial Vehicle (UAV) moving in a structured indoor environment utilizing the Cuckoo Search Algorithm (CSA). The UAV is to move from an initially specified starting point to a specified goal while avoiding known static obstacles in a three-dimensional grid space. The CSA is calibrated using parameter sensitivity analysis with population size, step size factor, discovery rate, and fitness weighting. The calibrated model is verified by 20 trials in MATLAB-based simulations and real-time experiments on a nano drone using a Pixhawk Mini flight controller and Raspberry Pi. Experimental settings mimicked the simulated environment with a grid size of $420 ~\text{cm} \times 720 ~\text{cm} \times 150 ~\text{cm}$. The UAV only had an average path length error of 8.18 % and a travel time error of 7.82 % between simulation and physical tests, with no collision events occurring. The findings support that the devised CSA framework is efficient, stable, and could be transferred to physical UAV systems for indoor navigation tasks.
