TITLE: LiDAR-Based Real-Time 2D Mapping for Autonomous Vehicles Using Hector SLAM on an Embedded Jetson Orin Nano Platform

YEAR: 2026
VENUE: NOT_IN_ABSTRACT

ABSTRACT: Simultaneous Localization and Mapping (SLAM) is a critical capability for autonomous navigation, particularly in GPS-denied indoor environments. This study presents a realtime 2D map generation method by integrating high-frequency LiDAR data with the Hector SLAM algorithm on an embedded computing platform. Onboard computation is performed using an RPLidar A1M8 sensor and an NVIDIA Jetson Orin Nano running the Robot Operating System (ROS) framework. By applying Gauss-Newton optimization for scan-to-map matching, the system demonstrates robust performance in both static and dynamic indoor settings. Experimental results indicate that while higher scanning frequencies improve temporal resolution, they significantly reduce scan density. Among the tested configurations (5 Hz, 10 Hz and 15 Hz), 10 Hz was identified as the optimal trade-off, providing 1073 points/scan and superior map consistency.
