TITLE: Comparative Analysis of A * Algorithm and Deep Deterministic Policy Gradient for Autonomous Navigation in Indoor Environment
AUTHORS: A. A. S; M. Menon; A. Robens; M. P. V.
YEAR: 2025
ABSTRACT: This paper presents a comprehensive comparative analysis of two distinct navigation algorithms-A * algorithm and Deep Deterministic Policy Gradient (DDPG)-for autonomous navigation in indoor environments. The research addresses the critical need for efficient path planning and obstacle avoidance in robotic systems through intelligent navigation algorithms. A * algorithm provides discrete, grid-based navigation with prede-fined step-by-step pathfinding, while DDPG offers continuous, real-time path adjustment based on reinforcement learning principles. Both algorithms were implemented and tested in simulated indoor environments with static and dynamic obstacles. The hardware prototype, built using ESP32 microcontroller, ultrasonic sensors, and DC motors, successfully demonstrated autonomous navigation capabilities. Results indicate that A * algorithm excels in structured, controlled environments with 100% obstacle avoidance accuracy for static scenarios, while DDPG shows superior adaptability in dynamic environments with continuous movement control achieving 95 % success rate. The comparative analysis reveals distinct advantages of each approach, providing valuable insights for future autonomous navigation system development. The study contributes empirical evidence for algorithm selection based on environmental con-straints and application requirements.
