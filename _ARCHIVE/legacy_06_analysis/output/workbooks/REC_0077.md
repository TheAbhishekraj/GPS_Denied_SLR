Abstract— This paper presents a UAV path planning 
framework designed to enable smooth, collision-free navigation 
in static, GPS-denied environments. The framework relies on 
point cloud data collected by a primary, pilot UAV, which uses 
onboard sensing, SLAM, and object detection to incrementally 
map an unknown environment and identify waypoints. Path 
planning is performed in a bounded SE(3) state space using 
sampling-based algorithms with a multi-objective formulation 
that balances path length, obstacle clearance, and orientation 
smoothness. Safety is ensured through tight integration with a 
dedicated collision detection and proximity query engine, 
enabling efficient collision and distance queries against the 
octree-based environment representation. Planned paths are 
further refined through shortcutting and B-spline smoothing to 
produce dynamically feasible trajectories, which are executed 
via a MAVROS–PX4 control pipeline. The enhanced collision 
validation approach for global path planning incorporates 6-
DOF vehicle motion to facilitate accurate navigation. Simulation 
and flight test results demonstrate the effectiveness of the 
proposed framework for reliable UAV navigation in complex 
and GPS-denied environments.  
I. INTRODUCTION 
The rapid advancement of Unmanned Aerial Vehicle 
(UAV) technology has driven significant growth in 
applications such as autonomous navigation, search-and-
rescue, precision agriculture, and package delivery. However, 
the increasing prevalence of GPS spoofing [1], [2] and 
jamming [3]  attacks on UAV platforms has underscored the 
need for robust navigation solutions capable of operating 
reliably in GPS-denied environments. While progress in 
mapping technologies has enabled high-fidelity three-
dimensional environmental representations [4], which can be 
leveraged to support advanced path planning strategies [5], [6], 
implementing these strategies requires navigation frameworks 
capable of handling complex environments [7], [8]. Many of 
the existing works only consider point mass models of the 
vehicles for simulation studies. While useful for preliminary 
studies, these point mass models do not represent six-degrees-
of freedom motion of the vehicle. In addition, point mass 
models do not provide information on turn rate and turn radius.  
For successful flight tests, it is essential to integrate enhanced 
collision avoidance mechanisms and trajectory smoothing 
algorithms to ensure safe, stable, and reliable flight during 
fully autonomous missions. This work aims to enhance such 
path planning refinement strategies by modeling the UAV as a 
bounded rigid body within an SE(3) state-space and perform 
geometry-aware collision and proximity queries against a 
volumetric occupancy map. This approach will allow collision 
validation to account for the vehicle’s physical dimensions and 
orientation, providing a more conservative and physically 
representative safety assessment during global path planning 
in static environments.

II. PATH-PLANNING PIPELINE 
The path-planning pipeline implements a complete end-to-
end framework for safe autonomous UAV navigation in 
cluttered, GPS-denied environments using volumetric 
mapping [4] and sampling-based motion planning [9]. The 
pipeline consists of five distinct stages. First, the system 
ingests a probabilistic three-dimensional (3D) occupancy grid 
generated from simultaneous localization and mapping 
(SLAM) algorithms and onboard sensors, along with detailed 
planning parameters, vehicle geometry, safety margins, and 
workspace bounds that define the feasible search space and 
risk tolerance. Second, the planner is configured to operate 
over a bounded SE(3) [10], special Euclidean group in 3 
dimensions state-space, and to optimize a weighted 
combination of path length, obstacle clearance, and 
orientation smoothness, enabling principled trade-offs 
between efficiency, safety, and dynamic feasibility. Third,

A. Concept of Operation  
As the UAV navigates an unknown environment, a 
stereovision sensor onboard the UAV acquires synchronized 
RGB and depth images, complemented by inertial 
measurements from the onboard IMU. These sensor streams 
are processed by onboard modules for marker detection, 
SLAM, and visual–inertial odometry (VIO). The resulting 
map and generated waypoints are then compressed into a 
format that can be transmitted wirelessly to the ground control 
station or shared with other UAVs for coordinated navigation. 
As illustrated in Fig. 1, upon receiving the transmitted data, 
the onboard computer begins the path planning procedure. The 
resulting path is then translated into an autonomous mission 
and uploaded to the flight controller for execution via 
MAVROS. During navigation toward the target location, the 
SLAM module continuously provides visual odometry, 
enabling smooth and stable flight within the newly mapped 
environment. Upon reaching the target, the UAV may proceed 
to the next waypoint by generating a new MAVROS mission 
for the subsequent target. Once all waypoints within the 
surveyed area have been visited, the UAV can return to a 
predefined location for landing. The following subsections 
detail the path planning and refinement procedures.

B. Inputs  
The planner is initialized with a volumetric representation 
of the environment and a set of configuration parameters that 
define how safe, efficient, and feasible paths are generated. 
The primary input is a 3D OctoMap [12] occupancy grid 
produced by SLAM and onboard sensors, and published on a 
ROS2 topic, which encodes occupied, free, and unknown 
space at a configurable resolution suitable for real-time UAV 
navigation. On top of this map, a sampling-based geometric 
planner (e.g., RRT, RRTConnect, RRT*, or related variants 
[9]) is selected and parameterized by limits on planning time, 
maximum extension range, goal bias, and state validity 
resolution, which together control convergence speed and 
solution quality. In the simplest case, the UAV is modeled as 
a spherical body with a defined radius, inflated by a clearance 
factor to enforce conservative collision checking and safety 
margins during planning and cost evaluation. Path 
optimization further balances competing objectives through 
weighted costs on total path length, obstacle clearance 
(typically emphasized to prioritize safety in cluttered 
environments), and smoothness of orientation changes. After 
a candidate path is found, optional post-processing such as B-
spline smoothing is applied to improve trajectory continuity, 
with configurable handling of unknown voxels and optional 
replanning behavior on failure. Finally, the planner operates 
within a bounded SE(3) workspace, either automatically 
inferred from the OctoMap extents or explicitly defined by 
user-specified spatial limits, ensuring that planning remains 
computationally tractable and physically meaningful. 
C. Setup and Optimization Objectives 
The planning framework is configured to operate over a 
bounded SE(3) state-space that explicitly models both the 
UAV’s 3D position and orientation, with spatial limits derived 
from the workspace to constrain the search region. Path 
generation and refinement are driven by a multi-objective 
optimization framework in which several competing criteria 
are combined into a single cost function. The first objective 
minimizes total Euclidean path length by summing the 
distances between consecutive states and leveraging 
admissible cost-to-go heuristics for efficient convergence. 
Second, a custom clearance objective prioritizes safety by 
penalizing proximity to obstacles through an inverse-distance 
formulation, where clearance is computed via distance queries 
between the UAV’s spherical collision model and the occupied 
voxels, ensuring paths through narrow or cluttered regions 
incur higher costs while invalid or out-of-bounds states are 
excluded. The third objective minimizes orientation changes 
by penalizing angular differences between consecutive 
quaternions and deviations from a nominal upright attitude, 
promoting smooth rotational behavior that improves flight 
stability and reduces mechanical stress. Equation 1 shows the 
full cost function to be minimized,

To summarize, motion validation and collision detection 
are implemented by tightly integrating the path planning 
module and a geometric collision-checking framework to 
ensure that both individual states and entire motion segments 
are physically feasible within the mapped environment. The 
static environment is represented as an octree geometry that 
directly wraps the occupancy grid produced by SLAM, while 
the UAV is modeled as a collision geometry; by default, a 
sphere for computational efficiency, though the framework 
supports more other primitive shapes or full mesh models 
when needed. During planning, each SE(3) state, which 
encodes position and orientation as a quaternion, is converted 
into a homogeneous transform that places and orients the UAV 
geometry in the world; this conversion forms the critical 
bridge between the abstract state space and concrete geometric 
queries. A custom state validity checker then uses this 
transform to perform fast collision tests and distance queries 
against the octree, first rejecting out-of-bounds or occupied 
states via OctoMap lookups and then invoking collision-
checking or distance-checking routines to determine feasibility 
and clearance. For motion validation, the planning module 
discretizes candidate edges between states according to a 
configurable resolution, interpolates both position and 
orientation along the segment, and checks each intermediate 
state for collision, ensuring that no obstacle is intersected 
between samples. This discrete motion validation strategy, 
combined with efficient octree-based collision queries, 
provides a robust and conservative safety guarantee while 
balancing computational cost, making it suitable for real-time 
UAV planning in complex 3D environments.

The initially feasible path produced by the planner is 
refined through a sequence of post-processing operations to 
improve efficiency, smoothness, and executability while 
preserving safety. First, path shortcutting is applied using

OMPL’s partial shortcut algorithm, which randomly selects

producing

that are more suitable for downstream velocity and 
acceleration control and that enhance flight stability at the cost 
of a potentially minor increase in path length. Before the 
refined path is accepted, it is subjected to strict validation 
criteria: it must contain a sufficient number of waypoints to 
support meaningful smoothing, and its terminal state must lie 
within a conservative tolerance of the goal to ensure safe goal 
attainment. If these checks fail, the system can optionally 
trigger a single replanning attempt with an extended timeout, 
allowing more thorough exploration while preventing 
unbounded retries, ensuring that only safe, smooth, and goal-
consistent trajectories are returned to the UAV controller. 
F. Output and Path Following 
A successfully planned and refined trajectory is converted 
into a ROS-compatible representation and executed by the 
UAV through a MAVROS-based path-following pipeline. The 
planner outputs the solution as a series of navigation messages, 
extracting 3D positions and corresponding quaternions from 
the SE(3) states, stamping the message with the current time 
and publishing it in the map frame to ensure consistency with 
the OctoMap and the global planning context. This path is 
consumed by a dedicated path follower node to generate an 
autonomous MAVROS mission. The mission operates in 
OFFBOARD mode and publishes position setpoints at a fixed 
control rate to the MAVROS local position interface. The 
follower sequentially tracks each waypoint, advancing only 
once the UAV reaches the current target within a specified 
tolerance, while allowing execution speed to be modulated 
through a configurable scaling factor and enforcing basic 
safety constraints such as altitude limits and automated landing 
upon completion. Correct execution relies on a coherent ROS 
transformation tree (Tf2 tree) [13] that aligns the planner’s 
map frame, the OctoMap frame, and MAVROS’s local frame, 
ensuring that planned waypoints correspond to physically 
meaningful positions in the flight controller’s coordinate 
system. By preserving full SE(3) information in the output, the 
system not only enables position-based navigation but also 
supports orientation-aware behaviors, such as controlled yaw 
or sensor pointing, and provides a foundation for more 
advanced, constraint-aware flight control in future extensions.

The custom UAV features a 3D-printed chassis with 
carbon-fiber arms and landing legs, equipped with a stereo-
depth camera, a LiDAR sensor, and an onboard computer. The

Nano modules are deployed on smaller UAV platforms where

B. Software 
The software stack is built around a modern ROS 2–based 
autonomy pipeline and is designed to support reliable UAV 
navigation in GPS-denied environments. The system runs on 
Ubuntu 22.04 (Jammy Jellyfish) as the host operating system, 
providing long-term support, a stable kernel, and compatibility 
with contemporary robotics and UAV middleware. On top of 
this, ROS 2 Humble serves as the core robotics framework, 
handling inter-process communication, message passing, 
lifecycle management, and the TF transform tree that 
maintains consistent spatial relationships between sensor, 
map, and vehicle frames. 
At the perception and mapping layer, onboard sensors such 
as LiDAR or depth cameras provide point cloud data to SLAM 
and mapping nodes that generate a continuously updated 
probabilistic OctoMap, which encodes free, occupied, and 
unknown space and serves as the shared 3D world model for 
navigation in ROS 2. Building on this representation, the 
planning layer uses the Open Motion Planning Library [14] 
(OMPL) to perform sampling-based motion planning in a 
bounded SE(3) state-space, optimizing for path length, 
obstacle clearance, and orientation smoothness while 
leveraging the Flexible Collision Library [15] (FCL) for 
efficient collision and distance queries against the OctoMap. 
The resulting paths are post-processed using OMPL’s 
simplification and smoothing tools to produce smooth, 
dynamically feasible trajectories, which are then published as 
standard ROS 2 navigation messages. Finally, at the control 
and execution layer, the PX4 flight controller executes these 
trajectories via MAVROS, with a ROS 2 path follower 
operating in OFFBOARD mode to convert planned waypoints 
into continuous position setpoints while enforcing safety 
constraints and managing mission execution. 
Supporting this core pipeline are standard ROS 2 tools and 
libraries, including TF2 for coordinate transformations, Eigen 
for linear algebra, PCL for point cloud handling, and

V. CONCLUSION 
This work presented a comprehensive UAV path planning 
framework tailored for reliable operation in static, GPS-denied 
environments. By leveraging a probabilistic 3D occupancy 
map, the system enables autonomous UAV navigation toward 
mission waypoints in complex surroundings. The proposed 
planning architecture integrates sampling-based motion 
planning in SE(3) with a multi-objective optimization strategy 
that explicitly balances path efficiency, obstacle clearance, and 
orientation smoothness. Whereas most existing approaches 
rely on simplified point-mass vehicle models, the framework 
also accounts for the aircraft geometry in the representation of 
6-DOF vehicle motion during global planning and collision 
validation, enabling more accurate and conservative safety 
assessments through dedicated proximity and collision queries 
against an octree-based world model. Post-processing through 
shortcutting and B-spline smoothing further enhances 
trajectory feasibility and flight stability, while seamless 
integration with a MAVROS-PX4 control pipeline ensures 
practical deployability on real UAV hardware. Simulation and 
flight testing demonstrate that the framework produces 
smooth, collision-free trajectories and maintains robust 
performance in cluttered, GPS-denied environments.   
 Future work will extend the framework to dynamic 
environments with real-time replanning for moving obstacles 
and improved computational efficiency for multi-UAV 
scalability, including search-and-rescue applications. These 
enhancements will further strengthen the reliability and 
autonomy of UAV operations in GPS-denied environments.
