and

cluttered forest-like canopy environment is presented. A robust 
multi-sensor fusion-based robust navigation method which has

autonomous navigation. The autonomy architecture utilizes the 
navigation, planning, and control capabilities of the UAV in a

a simulated environment and the result shows the capability of 
autonomous flights in such a challenging environment. The 
performance of the autonomous flight was evaluated based on 
mean velocity and path length with respect to the increasing 
number of trees in the forest.

I. INTRODUCTION  
 
Nowadays, Unmanned Aerial Vehicles (UAV) with 
autonomous capabilities are useful for applications such as 
structure inspection, agriculture, land survey, and many more. 
Most of the commercial UAVs used in forest and agricultural 
survey applications rely on GPS-based navigation. For 
management of forest resources and research on forest 
ecosystems, collecting tangible data such as: tree Diameter at 
Breast Height (DBH) parameters are crucial. Several sensors 
can be incorporated on UAV to perform these tasks. However, 
conventional GPS based UAV navigation is not capable for 
collecting data in under-canopy forest environment which is 
cluttered, dynamic, GPS denied and large scale [1]. Therefore, 
designing an autonomous UAV to perform autonomous 
missions in that environment cannot be conducted in a 
straightforward approach. Two most important mission 
requirements while designing autonomous robots for such 
applications are (1) reliable navigation system and (2) 
autonomous mission planning.  
  State estimation is one of the most important elements of 
any autonomous UAV. Different sensing modalities have 
been used for state estimation such as camera, Inertia 
Measurement Unit (IMU), LiDAR, GPS, etc. Many research 
works have been conducted on designing different 
Simultaneous Localization and Mapping (SLAM) and sensor 
fusion algorithms for UAV navigation. Ji Zhang et 
al. proposed a real-time state estimation method using 2D 
LiDAR which can produce outputs of 6D pose estimation and 
mapping [2]. Woong Kwon et al. have proposed autonomous 
UAV navigation in the warehouse with Extended Kalman 
Filter (EKF) based sensor fusion approach [3].

 Xu Liu et al. proposed UAV navigation in the forest using the

of the odometry algorithms are based on geometric feature 
tracking methods but this can increase the drift over a large-
scale environment. Autonomous exploration in GPS denied 
forest under-canopy without any external navigation system 
can be challenging.

II. SYSTEM OVERVIEW 
This section will describe the autonomous UAV 
navigation architecture which is based on robust sensor 
fusion-based framework. The overall system architecture 
diagram is shown in Fig. 2. The system takes input from 
multiple heterogenous sensors including IMU, Stereo cameras 
and 2D LiDAR. The input feeds the data in state estimation 
block where multiple odometry algorithms will be running in 
parallel and fused. The best pose estimation and range data 
will go the planning and control module for the autonomous 
navigation. The planning block is divided into two local and 
global planners. The local planner is responsible for finding 
obstacle free feasible path and global planner will take of 
overall mission plan. In the cascade control architecture, 
trajectory controller will control the desired trajectory and 
attitude controller will be running on the flight controller and 
send motor commands to electronics speed controllers. 
A. UAV & Sensing 
The UAV system is simulated in a Gazebo simulator. The 
UAV is equipped with various redundant sensing modalities 
to ensure a robust state estimation in an unstructured under-
canopy environment. The system utilizes visual-inertial and 
lidar-based sensing modalities. Global shutter cameras are 
lightweight and have high update rates which make them a 
good candidate for UAV sensors. Fusing a global shutter 
camera with inertial sensing can make a reasonable state 
estimation of Visual Inertial Odometry (VIO) system [6,7]. 
But the fluctuation of the sunlight illumination under-canopy 
can affect the VIO visual feature tracking performance. To 
compensate this limitation, a visual-inertial navigation 2D 
LiDAR is used although they are quite big and expensive.   
B. State Estimation (Sensor Fusion)  
A robust multi-sensor fusion framework is proposed for 
6D 
UAV 
state 
estimation 
in 
forest 
under-canopy 
environments. The proposed sensor fusion architecture 
prioritizes the robustness of the autonomous UAV localization 
by addressing the redundancy both in sensing hardware and 
state-estimation algorithms shown in Fig. 3. The main purpose 
of this proposed architecture is to identify the failures in the 
system and react to recover the system for a safe robot 
mission. The proposed architecture consists of 3 key modules: 
1) Sensor health check, 2) Odometry algorithms, and 3) EKF 
data fusion. 
1) Sensor health check:  Correct data from sensors will 
give better state estimation. As the forest environment is 
complex and unstructured, the sensor reading could be faulty 
and noisy. To handle this, sensor health check feature is 
introduced as in Fig. 3. Earlier detection of sensor failure can 
help the UAV to navigate safely or in case of failure, it can 
initiate the fail-safe protocol. For the camera input, the image 
intensity and illumination will be checked to detect the 
varying condition. For LiDAR and IMU-based systems, data 
output rate and invalid scan points will be counted for 
anomaly detection.   
 
Fig. 3. 
System overview of proposed robust sensor fusion framework. 
2) Odometry Algorithm Stack:  In the odometry algorithm 
stack module, multiple odometry algorithms will be used to 
run in parallel to refrain failures of any single odometry a 
algorithm [9]. The proposed approach combines multiple 
odometry methods into a redundant system, which is robust to 
failure cases and provides better state estimation results. There

are no special requirement on the type of algorithm, with the 
ability to incorporate either tightly or loosely coupled 
approaches. As the proposed system is modular, different VIO 
and LiDAR Odometry (LO) algorithms can be used 
depending on the mission requirement of the UAV. For the 
validation of our proposed approach in the forest under a 
canopy environment, we have selected VIO and 2D LiDAR 
odometry. Both of these odometry algorithms will be running 
in parallel. 
a) Stereo Visual Inertial Odometry (S-VIO): For visual stereo 
odometry, we use stereo MSCKF for 6D pose estimation by 
fusing data from a stereo camera and synchronized IMU. An 
intel real sense T265 tracking sensor simulated hardware was 
used in the gazebo simulator. The output data from the VIO is 
published as position and orientation with covariance matrices 
of 20 Hz.    
b) Lidar Odometry (LO): Scan matching ICP-based Hector 
SLAM is used as lidar odometry for 6D pose estimation. 
Simulated RP-Lidar A2 is used as the LO. The output data 
from LO is published as position and orientation with 
covariance matrices of 10 Hz.    
3) Odometry Fail Check:  In the fail check module, faulty 
data from the odometry algorithms are checked based on three 
key criteria. 
a) Gap: Most of the odometry algorithms like VIO, and LO 
use feature tracking methods for pose estimation. However, in 
a forest under-canopy environment where the UAV is moving 
fast, failure may occur due to the varying light illumination 
feature tracking which will decrease the rate of pose 
measurement updates. This will create faulty data gap that can 
be detected. 
b) Jump: State estimation algorithm may fail to give correct 
estimation where it will give inconsistent pose data that affect 
in planning and control of the UAV. By checking the instant 
changes in pose data, faulty estimation of the odometry 
algorithm can be detected.   
c) Divergence: Odometry algorithms may fail to estimate the 
state the uncertainty of the pose data either increases and 
diverged. From the covariance matrix uncertainly, the 
divergence of the data can be detected.

in a modular way [8]. The estimation from the EKF algorithm

C. Planning 
Autonomous navigation in cluttered GPS denied under-
canopy environment can be challenging.  For such autonomy 
mission state estimation, planning and control need to be 
performed simultaneously [1,10]. The planning process is 
divided in two main steps as shown in Fig. 5. First step is to 
plan the mission locally where local-planner is responsible for 
obstacle avoidance to go to certain given waypoints given by 
the user. The user can give a certain waypoints in Cartesian 
coordinates. The UAV navigates to those selected points to 
start local supervised exploration. Along the way, the UAV 
creates a global voxel map which is used by the global-planner 
for return to home and reused for further exploration and 
planning. Potential field method was used by the local-planner 
to create obstacle free feasible paths for local exploration and 
obstacle avoidance. The global planner uses “A star” graph 
searching technique to plan the shortest path in the voxel grid 
map. The planning is done in 2D (X-Y) plane and the Z axis 
of UAV height is considered as constant and it can be preset 
by the user.

III. EXPERIMENTAL SETUP 
The proposed system is developed and tested in the gazebo 
physics engine simulator as shown in Fig. 7. The simulation 
method was considered for testing the proposed robust sensor 
fusion framework and autonomous navigation in a cluttered 
forest under-canopy environment. We have created a 
simulated forest area of 250 m2 . The simulated environment 
was created based on data collected from real forests with 
average gap was set to 1.8 m between each tree. A custom 
UAV model was created in the gazebo SITL simulator with 
pixhawk-based control. The UAV is equipped with 2D lidar 
and stereo tracking camera. We have created 5 sample 
environments with a different number of trees: 20, 40, 60, 80 
and 100. Different samples were prepared for rigorous testing 
of autonomous flights in the cluttered forest environment to 
evaluate the performance of the autonomous flight based on 
mean velocity and path length with respect to different number 
of trees.         
IV. RESULT & ANALYSIS 
The first experiment evaluates the proposed robust sensor 
fusion framework. For evaluation of the proposed robust 
sensor fusion framework, we took different odometry data 
samples from random time sequence. For qualitative analysis, 
pose estimation from different odometry algorithms are 
compared to our proposed robust sensor fusion odometry. Fig. 
8 shows the  individual odometry performance for X position 
estimation of SFO, LO and VIO. From the figure, Lidar 
Odometry (LO) estimates nearly similar X position as 
proposed SFO with some small noise. However, VIO gives 
more noise respond compared to our proposed sensor fusion 
odometry (SFO).

Autonomous navigation in cluttered forest canopy 
environment is challenging. Any failure from the state 
estimation pipeline can effect on the quality of planning and 
control of the UAV and can lead to navigation failure. To 
achieve large scale autonomous navigation, the UAV needs to 
move fast as considering limited battery capacity. However, 
in fast motion, the conventional state estimation odometry 
algorithm can fail due to large drift and feature tracking error 
that affect the sensor perception visibility. Considering these 
challenges our proposed sensor fusion was designed with 
robust and redundant features.  
V. CONCLUSION 
In this work, we successfully demonstrated in simulated 
environment on how autonomous UAV can navigate in such 
cluttered forest, GPS denied environment autonomously. 
UAV can be used with different sensors to collect tangible 
forestry data such as DBH parameter, tree volume, tree density 
for forest research and its biodiversity. Other application such 
as search and rescue operation in GPS denied environment is 
also possible with this technology. The performance of the 
autonomous flight was evaluated based mean velocity and 
path length with respect to the increasing number of trees. We 
have integrated our proposed robust sensor fusion based state 
estimation method in the autonomous flight to reduce of drift 
over long time. We believe that the findings will serve as a 
catalyst for further research in aerial autonomous navigation 
in real world challenging application. Graph based 
optimization and smoothing framework like LOAM, LIO-
SAM can reduce the global drift of our proposed EKF based 
sensor fused state estimation. We will further explore this in 
future work and validate the system in actual scenario with 
real hardware.
