Abstract—This paper presents a reliable vision-based naviga-
tion system for guided aerial vehicles operating in GPS-denied
environments. The proposed approach uses deep learning models
trained on aerial map patches and high-resolution images cap-
tured directly by the unmanned aerial vehicles (UAV), enabling
accurate position estimation without relying on GPS signals. By
matching onboard visual information with preprocessed map
data, the system enables accurate and stable position estimation.
Experimental results show stable localization accuracy, with most
positioning errors ranging between 5 m and 15 m using only
vision sensors. Moreover, the system generalizes well to previously
unseen areas without requiring additional GPS information,
making it suitable for autonomous UAV navigation in GPS-denied
environments.
Index Terms—Vision-based navigation, Unmanned Aerial Vehi-
cles (UAVs), GPS-denied environments, Visual localization, Image
retrieval, Map-based localization, Convolutional Neural Networks

I. INTRODUCTION
Unmanned aerial vehicles (UAVs) are becoming essential
in many applications, such as disaster response, precision
agriculture, search and rescue, and industrial inspection. A
key challenge for UAVs is maintaining reliable navigation,
especially in environments where GPS signals may be
blocked, jammed, or unavailable [1]. In such cases, reliance
on GPS can lead to mission failure or increase the risk of
accidents. Therefore, it is important to develop navigation
methods that enable UAVs to operate safely without depending
on traditional positioning systems.
To overcome these challenges, vision-based navigation
has emerged as a strong alternative. Advances in computer
vision and deep learning enable UAVs to use onboard
cameras to observe the environment and localize themselves.
Convolutional
neural
networks
(CNNs)
are
particularly
effective at extracting meaningful features from aerial images,
enabling accurate positioning even in complex or GPS-
denied environments. Recent studies demonstrate successful
applications in both urban and rural scenarios [2].
State-of-the-art vision-based UAV localization methods
using deep CNNs can be broadly classified into three
categories: i) direct position prediction [3, 4], which is fast
but less robust in complex environments; ii) feature matching
and image retrieval [5, 6, 7], which improves accuracy at
the cost of higher computation and memory; and iii) hybrid
methods [8, 9, 10], which combine CNN features with
geometric or probabilistic techniques to enhance robustness
and trajectory smoothness. Despite these advances, achieving
solutions that are simultaneously accurate, efficient, and
adaptable remains a challenge [11].
Several approaches have been proposed to further improve
localization accuracy. Some focus on feature alignment
across viewpoints to handle unseen areas, but require large
labeled datasets and struggle in dynamic environments [12].
Others incorporate geographic context for finer localization,
increasing system complexity and sensitivity to map quality
[13]. For example, TransGeo [14] matches UAV images
with pre-built maps using deep CNNs and achieves good
performance, but relies heavily on cross-view training data.
Building on these advances, this paper presents a vision-
based navigation system that combines deep neural networks
with map-patch matching. The proposed system achieves
localization accuracy within 5–15 meters in most cases using
only onboard data, even in GPS-denied environments, enabling
more reliable and autonomous UAV operation.

To support accurate vision-based navigation for the UAV,
high-resolution satellite imagery of a designated operational

The satellite map is divided into fixed-size patches (e.g.,

the correspondence between visual features and real-world

C. UAV Image Acquisition and Dataset Alignment
During operational flights, the UAV captured aerial images
at a nearly constant altitude with varying viewing angles using
a DJI (Zenmuse P1) camera (35 mm focal length). These
images provide real visual data with approximate location
coordinates, enabling the system to learn the relationship
between observed scenes and their positions. The images are
aligned with the nearest map patches based on location and
visual similarity to ensure accurate mapping.
D. Preprocessing and Data Augmentation
To improve model performance, both UAV images and map
patches undergo several preprocessing steps:
1) Histogram normalization: standardizes brightness and
contrast across images for consistent learning.
2) Noise filtering: removes sensor-related distortions to
produce cleaner images.
3) Resizing: adjusts all images to fixed input dimensions
required by the network.
4) Data augmentation: includes random rotations (e.g.,
±15◦), horizontal flips, and brightness variations to
improve generalization.
III. SYSTEM ARCHITECTURE
The proposed framework is a complete vision-based local-
ization system for UAVs operating in GPS-denied environ-
ments. It combines a deep visual feature encoder, a georefer-
enced map database, fast image-based localization module that
determines the UAV’s position by matching captured images
with a reference map database.
A.
Architectural Overview
The workflow consists of two stages: (1) an offline stage,
where a feature database is constructed from satellite maps,
and (2) an online stage, where incoming UAV images captured
by the DJI Zenmuse P1 camera are matched against the
georeferenced map database to estimate the UAV’s position.
The offline stage performs computationally intensive feature
extraction, while the online stage enables fast feature encoding
and retrieval for efficient localization in GPS-denied environ-
ments [15, 16].
The system uses two types of visual inputs: UAV-captured
RGB images and high-resolution satellite images. Both un-
dergo the same preprocessing steps, including resizing to
224×224 pixels, normalization using ImageNet statistics, and
optional histogram equalization to standardize brightness and
contrast, as shown in Fig. 2.
Each satellite map patch is georeferenced using its center
latitude and longitude, allowing the learned visual features to
be directly mapped to real-world coordinates.
Fig. 2: The End-to-End system pipeline, including database

localization pipeline. First, triplet-loss metric learning brings
similar regions closer and separates dissimilar ones. Second,
the search is limited to nearby areas to reduce confusion.
Finally, the UAV trajectory is smoothed to keep localization
stable. Together, these steps improve accuracy and reliability
when GPS is weak or unavailable. Table I shows the prepro-

The framework is flexible, supporting advanced feature ex-
tractors, such as transformer-based backbones, and techniques

A standard 4-state Kalman Filter (KF) is applied to im-
prove stability and reduce positioning noise. The state vector
includes the UAV’s position (x, y) and velocity (vx, vy), and
the KF uses a constant-velocity model to predict and update
states. This smoothing reduces errors and improves trajectory
continuity.
IV. SIMULATION AND RESULTS
A. Experimental Setup
The system was implemented in Python using PyTorch.
A high-resolution satellite map generated map patches, and
both map patches and UAV images were resized to 224×224
pixels and normalized using ImageNet statistics. Data augmen-
tation, including random rotations (0°, 90°, 180°, 270°), and
brightness and contrast adjustments, was applied to improve
robustness.
The visual encoder is based on ResNet50 with the final
classification layer removed, followed by a projection head
producing a 64-dimensional feature embedding for each im-
age. The network was trained using triplet margin loss with
the AdamW optimizer, which improves learning speed and
reliability while reducing overfitting [21].

The model was trained for a total of 12 epochs, during

At the same time, the mean GPS error on the validation set

V. CONCLUSION AND FUTURE WORK
A robust vision-based navigation system for UAVs operating
in GPS-denied environments is presented. By combining deep
CNN visual embeddings with a geo-referenced map, the
system can achieve accurate localization using only onboard
camera imagery. After filtering, localization errors are reduced,
trajectories are smoothed, and the effect of noisy measure-
ments is mitigated.
Experimental evaluation shows a mean localization error of
9.71 m, with most predictions within 5–15 m of the ground
truth, confirming the system’s reliability and effectiveness.
Trajectory visualizations demonstrate improved consistency
with the ground truth.
The system has a flexible structure, allowing for future en-
hancements such as more advanced visual encoders, additional
smoothing techniques, or sensor fusion with IMUs to further
improve localization accuracy and robustness. Future work
includes eliminating the need for UAV-specific training data by
using pre-trained networks from geo-referenced map patches
and implementing real-time localization for fully autonomous
operation.
