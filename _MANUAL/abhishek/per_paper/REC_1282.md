## 5. Proposed Method
Method name: NOT_REPORTED (lidar-inertial navigation system based on grid and shell features)
Category: LIDAR | SLAM
The paper proposes a lidar-inertial navigation system for UAVs in GNSS-denied environments with spatial grid structures. It includes a grid feature-extraction algorithm and a shell feature-extraction algorithm that use logical judgment. The extracted features are used to complete pose calculation based on assumptions of local collinearity of grid features and local coplanarity of shell features. The system uses a lidar-inertial fusion framework similar to LIO-SAM.
"To solve this problem, we propose a lidar-inertial navigation system based on grid and shell features in the environment." [p.1]
