## 2. Problem Statement
"One type of sensor is unable to achieve all of the quality requirements. For example, if only use GNSS as navigation signal reference, the signal may not be available in some conditions. If only use inertial measurement unit, the computation process of IMU will increase the error growth over time; and navigation tasks will lose the accuracy and reliability." [p.1].

## 3. Motivation
"To achieve the navigation quality, sensor data integration has been used as the solution. ... However the data fusion process increases the computational load. This results the increasing of the weight, size, complexity and energy consuming of the onboard computing unit." [p.1].
