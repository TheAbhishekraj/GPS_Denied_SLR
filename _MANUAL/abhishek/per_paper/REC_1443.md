## 2. Problem Statement
"To satisfy the autonomous relative navigation demand of unmanned aerial vehicle (UAV) formation in a GPS-denied environment, an angle-only relative navigation algorithm is proposed." [p.1]

## 3. Motivation
"Accurate relative navigation information can be obtained in a short time using the inertial navigation equipment (inertial measurement unit, IMU) carried by the UAV, but the relative navigation error diverges over time as the IMU's error drifts." [p.1]

## 5. Proposed Method
Method name: Angle-only relative navigation
Category: COOPERATIVE
The paper proposes an angle-only relative navigation algorithm for UAV formation. It decouples relative states into horizontal and altitude motion, establishes relative dynamic and measurement models, introduces a consensus constraint model, and designs a consensus-extended Kalman filter (CEKF).
"an angle-only relative navigation algorithm is proposed." [p.1]

## 6. System Architecture
- Platform: Tri-UAV formation
- Sensors: IMU, altimeter, magnetometer, pitot tube, optical camera
