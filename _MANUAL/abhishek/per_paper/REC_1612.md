## 2. Problem Statement
"As GPS becomes increasingly unreliable for future applications, localizing without it becomes more and more crucial, with computer vision seen as a key way forward." [p.1]

## 3. Motivation
"This work uses recent advances in machine learning (ML) to add significant capabilities to current autonomous vehicle visualization, enabling a host of new possibilities in applications ranging from indoor localization to space exploration." [p.1]

## 4. GPS-Denied Context
MIXED
"The focus on visual navigation comes as GPS is increasingly unreliable (jammed, spoofed, or disabled), or unavailable (indoor, or extraterrestrial environments)." [p.1]

## 5. Proposed Method
Method name: Minimalist visual navigation and multi-agent communication using semantic ML classification
Category: VISION_OBJECT | COOPERATIVE
"This paper will introduce a novel and minimalist approach to visual navigation and multi- agent communication using semantic machine learning classification and geometric constraints." [p.1]

## 6. System Architecture
- Platform: UAV (parafoil system discussed as application)
- Sensors: Camera (downward-looking)
- Compute: Consumer grade laptop (Intel Core i7 with Nvidia 750M GPU)
- Communication: RF-ranging (scalar distance to other agents)

## 7. Experimental Setup
- real_or_sim: SIM
- environment: Satellite image of 10.28 x 10.28 km flight test area in Eloy, AZ
- trials: 1000 simulations of 400 time steps each
- baselines: Single agent
- dataset: Places-CNN descriptor
