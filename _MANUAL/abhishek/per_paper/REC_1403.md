"Until now, air navigation systems have mainly relied on global navigation satellite systems (GNSS) on the worldwide spread global positioning system. ## 5. Proposed Method
Method name: SIMless GSM positioning
Category: OTHER
The paper proposes a positioning system based on GSM signals using a SIM-free approach. It uses USRP-E310 for sniffing and decoding GSM signals and a MATLAB algorithm for positioning based on Cell ID.
"Referencing the SIMless concept, a SIM-free system is described in this paper. The SIM-free system is supported by open data bases and permits the positioning based on the information sniffed from the signals broadcast by a set of several nearby base station of the GSM network." [p.1]

## 6. System Architecture
- Platform: Standalone device
- Sensors: USRP-E310 Software Defined Radio
- Compute: MATLAB
- Communication: GSM
"The extraction of the needed GSM information is done via the two first mentioned steps. Then, after using the USRP-E310 for sniffing the downlink broadcast GSM signals and after decoding these signals with the GNU Radio software, the Cell ID information is obtained" [p.2]
