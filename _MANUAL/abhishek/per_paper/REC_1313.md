## 3. Motivation

## 5. Proposed Method
Method name: Smart Hybrid VAINS
Category: HYBRID
The paper proposes a smart hybrid vision-aided inertial navigation system using monocular visual odometry based on optical flow and regression trees, Gaussian process regression (GPR) for drift prediction, and extended Kalman filter for data fusion.
"In this study, a novel smart hybrid vision-aided inertial navigation system is proposed based on the main idea of optical flow-based for vision-aided inertial navigation using regression trees." [p.1]
