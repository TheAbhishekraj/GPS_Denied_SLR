## 2. Problem Statement
"Robust state estimation is one of the key requirements for safe flight. For real-world flight, it is common to encounter complete darkness and low-texture environment, which may lead to the degradation of vision-based methods." [p.1-2]

## 3. Motivation
"This paper provides a detailed description of a distributed approach for lidar-based relative state estimation which can be adopted by the multi-UAV systems in GPS-denied environments." [p.1]

## 5. Proposed Method
Method name: NOT_REPORTED (distributed lidar-based relative state estimation)
Category: LIDAR | COOPERATIVE
The paper presents a distributed framework for lidar-based relative state estimation of multiple UAVs. It builds on a factor graph, using onboard sensors and computing. Keyframe strategy, lidar-inertial odometry, and inter-UAV loop closure detection with outlier rejection.
"In this paper, we present a distributed framework for the lidar-based relative state estimator which achieves highly accurate, real-time trajectory estimation of multiple Unmanned Aerial Vehicles (UAVs) in GPS-denied environments." [p.1]

## 6. System Architecture
- Platform: Multi-UAV system (3 UAVs)
- Sensors: 3D lidar (Velodyne VLP-16), IMU (MicroStrain 3DM-GX5-25)
- Compute: Intel i7-8550U CPU, 32 GB RAM onboard computer
- Communication: ROS, network bridge
"Each UAV is equipped with a 3D lidar and an IMU in order to run lidar-inertial odometry" [p.3]
"one of the aerial platforms of the multi-UAV system is equipped with a Pixhawk4 flight controller, a Velodyne VLP-16 lidar, a MicroStrain 3DM-GX5-25 IMU, and an onboard computer (Intel i7-8550U CPU, 32 GB RAM)" [p.7]
