## 5. Proposed Method
Method name: Fake GPS
Category: OTHER (optical flow + sonar + fake GPS)
The paper proposes a method for autonomous UAV navigation in GPS-denied environments using an optical flow sensor for ground velocity and x-y position, sonar for altitude, and a "fake GPS" signal. The PX4 firmware is modified to simulate GPS using predefined coordinates. The optical flow and fake GPS data are filtered by an Extended Kalman Filter for position estimation.
"To accomplish this, the UAV uses an optical flow sensor to determine the ground velocity and x-y position, and sonar for measuring the altitude. ... Using ROS and MAVLink, the communication can be modified to use 'fake GPS' data, instead of the actual GPS signal, to be published in the appropriate ROS topics to avoid GPS failures." [p.1]

## 11. Future Work
"Since most power plant inspections are to be conducted indoors, the UAV needs to be more stable [11,12].
