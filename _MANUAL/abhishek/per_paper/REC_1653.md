## 5. Proposed Method
Method name: 2-channel CNN-based visual localization
Category: VISION_OBJECT
The paper proposes a visual localization framework using a 2-channel convolutional neural network for image matching between UAV images and satellite tiles, with image preprocessing based on information entropy and granular segmentation.
"Firstly, a novel image preprocessing method based on information entropy and granular segmentation is presented which can significantly filtrate the Google tiles in the georeferenced area to parsimony set to reduce UAV localization time. Secondly, we introduce an end-to-end image matching method based on convolutional neural network and image preprocessing to realize UAV localization" [p.1]
