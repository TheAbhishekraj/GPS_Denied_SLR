## 1. Bibliographic Metadata
Jurevičius, R., Marcinkevičius, V., & Šeibokas, J. (2019). Robust GNSS Denied Localization for UAV Using Particle Filter and Visual Odometry. *Machine Vision and Applications*, 30(7-8), 1181-1190. https://doi.org/10.1007/s00138-019-01036-6

## 2. Problem Statement
"Conventional autonomous Unmanned Air Vehicle (abbr. UAV) autopilot systems use Global Navigation Satellite System (abbr. GNSS) signal for navigation. However, autopilot systems fail to navigate due to lost or jammed GNSS signal." [p.1]

## 3. Motivation
"To solve this problem, information from other sensors such as optical sensors are used. Monocular Simultaneous Localization and Mapping algorithms have been developed over the last few years and achieved state-of-the-art accuracy. Also, map matching localization approaches are used for UAV localization relatively to imagery from static maps such as Google Maps." [p.1]

## 4. GPS-Denied Context
MIXED

## 5. Proposed Method
Method name: Particle Filter localization with logistic/rectifying conversion functions
Category: VISION_OBJECT
"An application of Particle Filter localization was implemented with different image similarity to likelihood conversion functions." [p.8]

## 6. System Architecture
- Platform: UAV (quadcopter)
  "a downward-facing optical camera mounted on an autonomous aircraft" [p.1]
- Sensors: downward-facing camera, visual odometry (SVO)
  "Monocular Semi-direct Visual Odometry (abbr. SVO) with a downward-facing camera is used to calculate aircraft motion." [p.4]
- Compute: NOT_REPORTED
- Communication: NOT_REPORTED

## 7. Experimental Setup
- real_or_sim: SIM
  "This paper presents a new dataset from simulated flights in urban and forested environments using ortho photo maps." [p.4]
- environment: urban and forested environments (simulated)
  "12 flights are recorded and abbreviated using two characters and a number, e.g., UR-200, where the first character stands for environment (U for urban and F for forest)" [p.4]
- trials: 12 simulated flights, each run 10 times
  "A single combination of conversion function, a flight scenario, and a map used for matching is run for ten times" [p.5]
- baselines: ORB-SLAM2, SVO, Softmax, Linear conversion
  "This paper evaluates the Particle Filter localization algorithm against ORB-SLAM2 algorithm" [p.4]
- dataset: Simulated Aerial Imagery Dataset (USGS ortho photo maps)
  "Aerial ortho photo imagery was retrieved from USGS website" [p.4]

## 9. Ablation / Sensitivity
"Localization using the proposed logistic function with a parameter value of 0.2 was shown to provide the best results by ranking localization accuracy from all the conversion functions results." [p.8]
"Particle Filter localization achieved 43% higher accuracy using three times fewer computations than the baseline Softmax probability conversion function." [p.9]

## 10. Stated Limitations
"The results were only provided for the straight line flight trajectory, since ORB-SLAM2 was unable to complete whole trajectories on the other flight scenarios, while Particle Filter localization completed all flights." [p.9]

## 18. Best Combination & Accuracy
### 18.1 Best sensor combination
"downward-facing optical camera mounted on an autonomous aircraft" [p.1]

### 18.2 Best algorithm
"Particle Filter localization with logistic conversion function (v=0.2)" [p.8]

### 18.3 Best accuracy
2.6 times better accuracy than ORB-SLAM2 [p.1]

### 18.4 Baseline comparison at best configuration
"Particle Filter localization outperforms both SVO and ORB-SLAM2 with over 2.6 times higher precision in average." [p.7]

### 18.5 Conditions of best accuracy
"straight line flight trajectory" [p.9]

### 18.6 Trade-offs
"Localization using rectifying function with parameter values 0.2, 0.1, and 0.0 and logistic conversion function with parameter values 0.7, 0.4, and 0.2 has shown similar localization accuracy using maps of different dates, showing an ability to be robust to changes in the imagery." [p.9]

### 18.7 Generalization limits
"Other functions showed higher accuracy with similar maps and inaccurate results using other maps for image matching." [p.9]
