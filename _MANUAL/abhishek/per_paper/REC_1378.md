## 2. Problem Statement
"The drift of inertial navigation system (INS) will lead to large navigation error when a low- cost INS is used in microaerial vehicles (MAV)." [p.1]

## 3. Motivation
"GPS is based on satellite which can provide relatively consistent accuracy navigation; however, the satellite signals would be lost in city canyon or indoor environments [6, 7]." [p.1]

## 4. GPS-Denied Context
MIXED

## 5. Proposed Method
Optical flow sensor/INS/magnetometer integrated navigation scheme; HYBRID
"an INS/optical flow/magnetometer integrated navigation scheme is proposed for GPS- denied environment" [p.1]

## 6. System Architecture
- Platform: autonomous MAV
"the autonomous MAV is used as flight platform" [p.5]
- Sensors: optical flow sensor PX4FLOW, IMU MPU6050, magnetometer HMC3883L, ultrasonic
"the optical flow sensor is produced by 3D Robotics Corporation which is named as PX4FLOW... the IMU is MPU6050... the magnetometer is HMC3883L..." [p.5]
- Compute: STM32F103Z flight control processor
"STM32F103Z is selected as the flight control processor" [p.5]
- Communication: HC-12 wireless serial interface module
"HC-12 wireless serial interface module... is used to transmit the sensor's data from MAV to PC." [p.5]
