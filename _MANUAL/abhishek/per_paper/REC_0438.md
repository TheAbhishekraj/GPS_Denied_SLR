## 2. Problem Statement
"The goal of the present work is to develop a system able to autonomously track the path of a dynamic object." [p.1].

## 3. Motivation
"By following an object's path, reliance on obstacle avoidance strategies can be reduced, under the assumption that the object's path is free of static obstacles." [p.1].

## 4. GPS-Denied Context
MIXED
"The use of optical flow allows for localization in GPS-denied environments." [p.1].

## 5. Proposed Method
Method name: Object path following algorithm
Category: VISION_OBJECT
"This paper presents the development of an object path following algorithm for a quadcopter using on-board vision and localization." [p.1].

## 6. System Architecture
- Platform: "custom built quadcopter craft, as shown in Fig. 1. Its frame is based on a DJI Flame Wheel F450." [p.2]
- Sensors: "A MaxBotix XL-EZ4 sonar was used to provide accurate altitude measurements. An on-board Pixhawk flight controller with IMU was used... a PX4Flow optical flow sensor estimated craft velocity for use in dead-reckoning... a Pixy camera was used... A red ball (210mm diameter) was used as the object to track." [p.2]
- Compute: "These calculations were performed onboard the flight controller using the ArduCopter extended Kalman filter (EKF)." [p.2]

## 10. Stated Limitations
"The disadvantage of this method is drift caused by accumulation of small errors, although this is minimized due to the accuracy and high frequency of the measurements. For larger time periods, a method to correct the drift would likely be required." [p.3].

## 11. Future Work
"Future work will include more rigorous testing of the path following algorithm, investigating the effects of object speed and radius of curvature of the path. An alternative ground truth measurement based on real time kinematic (RTK) GPS, allowing for cm-level accuracy may be used." [p.5].
