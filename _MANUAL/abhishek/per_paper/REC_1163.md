## 5. Proposed Method
Method name: TERCOM-EKF and ViSensorRF
Category: HYBRID
"This study bridges that gap by comparing two fundamentally different methods: a Terrain Contour Matching algorithm-Extended Kalman Filter framework (TERCOM-EKF), and Visual-Inertial Sensor Fusion with Random Forest Regression (ViSensorRF), a machine learning approach based on Random Forest Regression (RFR)." [p.1]

## 7. Experimental Setup
- real_or_sim: SIM
"evaluated in a GNSS-denied simulation environment using PX4, Robot Operating System (ROS) 2, Gazebo, and QGroundControl" [p.1]
- environment: simulated Taif region terrain
"over a digital elevation model of the Taif region in Saudi Arabia" [p.1]

"Six trajectories were generated to evaluate both localization methods" [p.9]
- baselines: Fast-LIO, MINS, XGBoost
"compare its performance against other methods, including Fast LiDAR-inertial odometry (Fast-LIO), the Multisensor-aided Inertial Navigation System (MINS), and a machine learning-based approach, eXtreme Gradient Boosting (XGBoost)." [p.2]
- dataset: OS-RFODG synthetic dataset
"The dataset used in this study is publicly available on Hugging Face: https://huggingface.co/datasets/riotu-lab/os-frog-outdoor-uav-synthetic-dataset-tail-saudi-arabia." [p.14]

## 10. Stated Limitations
"The evaluation was conducted using a single regional dataset representing the Taif terrain, and the DEM was generated from real-world elevation data using the available open-source os-rfodg framework [42]. However, obtaining accurate, high-resolution DEMs across different regions worldwide remains a considerable challenge due to limited data accessibility, variations in spatial resolution, and regional restrictions on geospatial information." [p.13]

## 11. Future Work
