## 2. Problem Statement
"As we know, simulation technologies can verify the algorithms and identify potential problems before the actual flight test and to make the physical implementation smoothly and successfully." [p.1].

## 3. Motivation
"In our UAV project, the UAVs are expected to cooperatively and autonomously operate in GPS-denied foliage or urban environments. Light Detection and Ranging (LIDAR) based simultaneous localization and mapping (SLAM) algorithm needs to be simulated in real-time. According to our knowledge, most of the simulation systems are not 'real' enough." [p.1].

## 4. GPS-Denied Context
MIXED
"In this paper, we will introduce our newly developed 3D simulation system for miniature unmanned aerial vehicles (UAVs) navigation and control in GPS-denied environments." [p.1].

## 5. Proposed Method
Method name: ROS+Unity3D hybrid 3D simulation system
Category: OTHER (simulation framework)
"we develop a 3D simulator based on robot operation system (ROS) and a game engine, Unity3D. Unity3D has powerful graphics and can support high-fidelity 3D environments and sensor modeling which is important when we simulate sensing technologies in cluttered and harsh environments." [p.1].

## 6. System Architecture
- Platform: "miniature unmanned aerial vehicles (UAVs)" [p.1]
- Sensors: "LIDAR sensor, which is the key component for SLAM algorithm is modeled in details in Unity3D script." [p.2]; "A Hokuyo laser scanner" [p.4]; "Camera" [p.4]
- Compute: "ROS client and the Unity3D server" [p.3]
- Communication: "The interface between the ROS and the Unity 3D has been developed based on TCP/IP protocol." [p.2]

## 9. Ablation / Sensitivity
"However, if there are several UAVs run simultaneously in the same workstation, we find that FPS will drop dramatically. The main problem origins from 3D game engines. Usually, for Raycast in Unity3D, it run in the main thread of CPU. When we run several UAVs in the same workstation, Raycast calculation will take most of the CPU resource." [p.4].
