Abstract²This  paper  presents  a  low  computational 
approach  for  unmanned  aerial  vehicles  (UAV)  navigation  in 
GPS-denied environments. This approach is aiming to reduce 
computation  load  for  UAV  flying  mission  constraints.  Small 
size, light weight on board hardware are constraints for UAV 
deployment and flying missions. The on board processor should 
not be built with high complexity and should consume as little 
computing as possible. Most existing approaches use Kalman 
filter, extended Kalman filter, Unscented filter, or particle filter 
to fuse different types of onboard sensor data to estimate UAV 
position. We developed a data fusion architecture that does not 
use  these  filters.  We  use  an  ultra-light-coupling  fusion 
architecture. In this architecture, primary sensor and secondary 
sensor data are fused. When the secondary sensor is unavailable 
in most of the time, the UAV navigation uses the output of the 
primary sensor. When the secondary sensor signal is available, 
the  primary  sensor  is  re-aligned  using  the  secondary  sensor 
signal to bond the errors. In our approach, the primary sensor 
is Inertial Measurement Unit (IMU), and the secondary sensor 
inputs are from Ultra-wideband system (UWB). This approach 
is validated using demonstration of comparison of computing 
load, and simulation results for accuracy and reliability testing 
using UAV flying mission scenario.  
Keywords—data fusion, system architecture, UAV, ultra-light-
coupling, simulation, low computational load algorithm     
 
,  ,NTRODUCTION   
 
Unmanned  Aerial  Vehicles  (UAV)  have  been  used  in 
activities that are dangerous for human. In many missions, the 
constraints for UAV include lightweight and small size while 
need achieving the certain quality in accuracy and reliability 
for  navigation.  The  navigation  mission  is  achieved  by 
navigation sensors and onboard processing unit. To keep the 
lightweight and small size of the UAV body, the navigation 
sensor set and onboard processing unit should be lightweight. 
Widely  used  navigation  sensors  in  UAV  are  Global 
Navigation  Satellite  System  (GNSS)  receiver,  inertial 
measurement unit (IMU), camera, and ranging sensor.  
The  quality  attributes  that  a  navigation  system  should 
achieve  include:  accuracy,  availability,  reliability  (fault 
tolerance/recoverability), 
robustness, 
safety, 
security, 
response time. The development constraints that impact the 
navigation 
system 
are 
maintainability 
(analyzability; 
changeability;  testability),  usability  (learnability;  XVHU
friendly; 
operability), 
development 
complexity, 
cost 
constraint  (hardware,  development  cost),  time  constraint, 
mission constraints, client and supplier collaboration capacity 
[1]. 
One type of sensor is unable to achieve all of the quality 
requirements. For example, if only use GNSS as navigation 
signal  reference,  the  signal  may  not  be  available  in  some 
conditions.  If  only  use  inertial  measurement  unit,  the 
computation process of IMU will increase the error growth 
over  time;  and  navigation  tasks  will  lose  the  accuracy  and 
reliability.  To  achieve  the  navigation  quality,  sensor  data 
integration has been used as the solution. For example, use 
two sensors to integrate two types of measurement data for 
navigation decision, such as using fuse IMU with camera, or 
GPS  receiver  with  IMU.  The  data  fusion  is  completed  by 
processing  algorithms  that  are  embedded  in  onboard 
computing  unit,  such  as  Kalman  filter,  particle  filter,  or 
unscented filter. However the data fusion process increases the 
computational load. This results the increasing of the weight, 
size,  complexity  and  energy  consuming  of  the  onboard 
computing unit.  
In this paper, we present a low computational load data 
fusion  approach  for  UAV  flying  tasks.  The  onboard 
navigation  sensor  set  is  configured  using  an  Inertial 
Measurement Unit as the primary sensor, and a UWB system 
as the secondary sensor. The data fusion is designed in GPS-
denied environment for UAV tasks. The fusion process is only 
at the secondary sensor¶s available time to bond the primary 
sensor  errors.  To  validate  the  algorithm  accuracy  and 
reliability, we use demonstration and simulation approach to 
test  UAV  navigation  in  flying  scenario  when  GPS  is 
unavailable.  
This paper is organized as follows. Section II will review 
the  related  work.  Section  III  will  present  the  data  fusion 
algorithm.  Section  IV  will  present  the  demonstration  and 
simulation results. Section V will draw the conclusions and 
future research direction.

In  literature,  the  integration  architectures  have  4  types: 
uncoupled fusion, loosely coupled fusion, tightly coupled, and 
ultra-tightly coupled architectures [1-4]. 
In  ³uncoupled  fusion  architecture´,  GNSS  and  Inertial 
Measurement  Unit  are  treated  as  two  individual  navigation 
systems. Sensor switching approach is used when one sensor 
is needed as navigation input. No aiding is used from either of 
the sensor.  
In  ³loosely  coupled  architecture´,  GNSS  and  Inertial 
Measurement Unit are used as one navigation system. Errors 
in position, velocity and attitude are estimated as navigation 
system output.   
³Tightly coupled architecture´ takes inputs from inertial 
sensors and GNSS receiver. Integration algorithm estimates 
and outputs the position, velocity and attitude. The estimates 
of  position,  velocity  and  attitude  are  feedback  to  GNSS 
information [1, 4].  
³Ultra-tight fusion´ applies the IMU computed position to 
internal components of GPS receiver to aid GPS positioning 
computing [1]. 
In uncoupled architecture, filter algorithm is not used. The 
system  directly  takes  inputs  from  computed  navigation 
information from inertial measurement unit and GNSS. The 
independent  system  of  computing  position,  velocity  and 
attitude using measurement from Inertial Measurement Unit 
is called inertial navigation system (INS).   
In three types of sensor integration architectures of loosely 
coupled, 
tightly 
coupled 
and 
ultra-tightly 
coupled 
configurations,  the  widely  used  integration  algorithms  in 
literature include Kalman filter (KF), extended Kalman filter 
(EKF), Unscented filter, and particle filter [1-5]. 
These architectures use GPS as navigation data input. In 
many UAV tasks, satellite signals are blocked or unavailable. 
Sensors  that  can  be  used  in  GPS-denied  environment  are 
needed to aid UAV flying tasks. Possible sensors are UWB 
(Ultra-Wideband) system, camera, inertial measurement unit, 
beacons, and range sensors.  
For  UAV  applications,  the  weight  and  size  limit  put  a 
constraint for computational load of the onboard computing 
processor. Usually the computing processor of UAV is not a 
computer with powerful functions. It only processes the basic 
required  information  for  taking  sensor  input,  computing 
navigation  information,  driving  and  controlling  flight  of 
UAV.   
Less computation for these basic functions will reduce the 
complexity and size of the onboard computing processor.  
To reduce the computational load in integrated navigation, 
researchers  have  made  many  efforts.  A  state-vector  fusion 
approach was developed to reduce the computation in UAV 
mission by processing different types of sensor measurements 
in a number of local filter [6]. Shu et al. developed a Weighted 
Measurement Fusion Kalman Filter [7]. This approach used 
the similar propagation and update model in Kalman filter. 
But before applying raw measurements from different sensors 
into  Kalman  filter,  this  approach  integrated  all  the 
measurement as one input at Kalman filter update step.  All 
the  raw  measurements  are  weighted.  This  reduced  the 
computational  load  in  measurement  update  step.  A  recent 
research  on  a  low  cost  solution  for  UAV  used  a  modified 
Extended Kalman Filter to fuse INS and computer vision for 
GPS outrage or denied environment [8].    
 All  these  efforts  are  under  the  architectures  of  loosely 
coupled, 
tightly 
coupled 
or 
ultra-tightly 
coupled 
configurations. All the filter architectures include a process 
model and a measurement model. The filter process includes 
the  computation  of  state  update,  error  covariance  update, 
measurement  update  using  the  process  model  and 
measurement model.  
To  reduce  the  computational  load,  we  present  a  sensor 
fusion  approach  using  a  new  ³Ultra-Light-Coupling 
Architecture Design´ without computing and updating filter 
process model and measurement model. The following section 
will present this approach.

In this architecture, we use two types of sensors: primary 
sensor and secondary sensor. The UAV navigation outputs are 
directly from the navigation data using the primary sensor. In 
our sensor configuration, the primary sensor input are from 
IMU, and the secondary sensor inputs are from UWB.  
Ultra-wideband (UWB) positioning technology uses very 
low energy for short-range positioning and is able to achieve 
10-centimetre accuracy [9, 10]. In GPS-denied environment, 
UWB is able to provide positioning data to UAV navigation 
tasks in real time at short range. 
UWB positioning can be used in the environments that 
have UWB anchors deployment. In our approach, we use IMU 
to continually compute UAV position as Inertial Navigation 
System (INS). UWB is to aid INS. 
When UAV flies outside UWB deployment range, UWB 
signal  is  unavailable,  the  UAV  navigation  uses  the  time, 
attitude, velocity and position from INS. Once UWB signal is

The UAV navigation output is updated at each INS time. 
When the secondary navigation sensor signal is unavailable, 
the output of the UAV navigation system is the output of INS 
output. Once the secondary sensor signal is available, INS will 
use the position output of the secondary sensor to re-align the 
INS process. This will bond the error growth over time in the 
integration process.  
By using the secondary sensor to bond the error growth, 
the accuracy level of the navigation system is achieved. 
The fusion point of this approach is only at the time when 
the secondary sensor signal is available. The fusion method 
only  uses  this  available  position  data  from  the  secondary 
sensor to re-align the INS as the new initial values in INS 
computing. This re-alignment method is setting initial value 
of  INS  using  UWB  data.  Therefore  we  call  this  approach 
µUltra-Light-Coupling¶ approach.

9  CONCLUSIONS AND FUTURE RESEARCH  
 
This paper presented an ³Ultra-Light-Coupling´ data fusion 
algorithm for UAV navigation tasks. The aim of the approach 
is  to  reduce  the  computation  load  for  UAV  operation 
constraints.  The  approach  removed  the  filter  process  for 
navigation state prediction update and error covariance matrix 
update  using  process  model  and  measurement  model.  The 
navigation algorithm is based on primary sensor navigation 
when secondary sensor is unavailable. Whenever a secondary 
sensor data set is available, the primary sensor will start a re-
alignment  using  the  secondary  sensor¶s  data  to  correct 
positioning  errors.  This  µUltra-Light-Coupling¶  data  fusion 
bonds the positioning error to meet the accuracy and reliability 
requirements. 
Instead of using conventional Big O notation to analyse 
computation load, our ³Ultra-Light-Coupling¶ is validated by 
³demonstration´  using  architecture  component  comparison 
approach  and  flying  tasks  ³simulation´  approach.      We 
designed a sensor set using IMU as primary sensor, and UWB 
as the secondary sensor. UAV path is designed for navigation 
simulation. By comparison of designed UAV path and data 
fusion estimated position, the algorithm is validated to meet 
the accuracy and reliability requirements. 
Future research will be applying more types of navigation 
sensors for data fusion. The optimal sensor set for UAV tasks 
can be decided by comparison of navigation system accuracy 
and  reliability,  computational  load,  sensor  weight,  size  of 
different types of low cost sensors.
