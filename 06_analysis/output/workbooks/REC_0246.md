I. INTRODUCTION 
It is of utmost importance to rescue people from natural 
disaster zones as fast as possible. However, sometimes this is 
hard to achieve due to the inherited risk involved with sending 
humans to disaster zones. It is with advancements in 
technology that unmanned aerial vehicles (UAVs) can now 
represent a viable alternative to approach these scenarios. 
In recent years, the popularity of UAVs has increased to a 
point where these vehicles can now be used for various 
applications including search and rescue missions in both 
indoor and outdoor environments. The main advantages of 
these vehicles are that they are cheaper and simpler than their 
manned counterparts, and pose no or reduced threat to human 
operators. In addition, these vehicles can be equipped with 
commercial off-the-shelf and low-cost flight control systems 
or autopilots for autonomous waypoint navigation, thereby 
further reducing human involvement for these missions.  For 
autonomous navigations, UAVs depend on Global Positioning 
System (GPS) data. However, GPS may be partially lost in 
certain locations due to high-rise buildings or other 
obstructions and collapsed/damaged areas. GPS signal may 
also be unavailable due to GPS spoofing. In addition, GPS 
signal is not available in indoor environments. In order to 
compensate for the lack of partial or complete loss of GPS 
signals, this research focuses on the implementation of a 
Simultaneous Localization and Mapping (SLAM) technique 
for the localization and mapping of the GPS-denied areas to 
enable autonomous navigation of UAVs in such areas.

used to generate 3-D maps in real-time.

A. RTAB-Map 
RTAB-Map can effectively be used to create a 3-D maps. 
This algorithm can adjust its detection rate to accommodate 
the vehicle’s travel speed, which makes this a suitable solution 
for real-time operation. Its memory management is divided 
into long-term memory (LTM) and working memory (WM). 
Nodes are created from the environment and stored in the 
working memory. It then uses a weighting mechanism to rank 
which features of the environment are more important. This 
determines whether the nodes remain in WM or sent to LTM. 
The more a feature or location is observed, the higher they are 
valued because this indicates that the UAV visited the area 
more frequently. Fig. 1 shows the workflow for the RTAB-
MAP ROS.  
 
               Figure 1. rtabmap_ros architecture workflow. 
As can be seen in Fig. 1, the workflow starts with a stereo 
image fed into WM. The sensor data is then sent to short-term 
memory (STM), which becomes a node. This node is then 
evaluated in a loop closing direction. If it satisfies all 
conditions in the evaluation, the node becomes a new link, gets 
transferred into map data and becomes a point cloud 
information in the final map output. Once this cycle is finished, 
it gets transferred into the LTM and stays there until a loop 
closure is detected.   
III. TARGET DETECTION  
This project uses a deep learning algorithm for target or 
victim detection. The traditional algorithms are comprised of 
a combination of two smaller algorithms: one that conducts 
feature 
extraction 
and 
another 
for 
template 
matching/classifiers. Convolutional Neural Networks (CNNs) 
are a family of deep learning models that show significant 
improvements in accuracy and efficiency as compared to the 
traditional target detection algorithms [7]. It is an architecture 
based on the visual perception mechanisms of animals. CNNs 
use a linear operation called convolution and iterate over every 
pixel in an image. Three key features of CNN are equivalent 
representations, sparse interactions, and parameter sharing [8]. 
CNN architecture is made up of multi-building blocks, which 
consist of the Convolutional Layer, Pooling layer, Activation 
Function, Fully Connected Layer, and Loss Functions. The 
Convolutional Layer consists of convolutional filters, also 
known as kernels, which have a weighted value. The Pooling 
Layer generates feature maps using convolutional operations. 
The Activation Function maps the input to the output. The 
Fully Connected Layer is located at the end of the architecture 
and is connected to all the nodes of the previous layer. Loss 
Functions are used to calculate the error prediction. 
A. YOLOv3 
You Only Look Once (YOLO) is a CNN algorithm that 
only uses 1x1 convolutions in its convolutional layer [9]. The 
advantage of using this model is speed and performance, and 
can work even when operating on low performance systems. 
YOLO is also capable of classification and bounding box 
regression simultaneously, which makes YOLO extremely 
fast. YOLOv2, also known as YOLO9000 is an improvement 
of the YOLO model and uses Darknet-19 as its backbone 
feature extractor [10]. The “9000” in its name comes from the 
fact that the model can detect over 9000 object categories 
using a hierarchical model of visual concepts known as 
WordTree. 
The next iterative improvement comes from YOLOv3, 
which uses Darknet-53 as its backbone feature extractor, 
making the model more accurate at object detection [11]. 
Darknet-53 gives the model an additional 53 layers, totaling 
106 fully convolutional layers. While this does make YOLOv3 
slower than its predecessors, it has significantly greater 
accuracy. YOLOv3 can use 1x1 kernels on feature maps for 
three different sizes. This allows the model to have greater 
detection with smaller objects. YOLOv3 can also predict over 
10,000 bounding boxes per image, over 10 times that of 
YOLOv2. These features are what gives YOLOv3 greater 
accuracy while still maintaining the impressive speed found in 
YOLO algorithms. This project uses YOLOv3 for the 
identification of victims.

M. Payload Drop Mechanism 
The payload drop mechanism on the rescue UAV is used to 
drop rescue packages from the vehicle to the identified 
victims within a disaster zone. The payload drop mechanism 
is mounted upside down on the belly of the rescue vehicle. It 
includes a servo motor, a motor mount, a crank, a jointed rod, 
and a piston. The design is shown in Fig. 20 on the right, and 
it consists of a base plate that sits along the frame of the 
vehicle, mounting parts for the servo motor, and a piston 
guide. As shown in the figure on the left, the mechanism acts 
as a piston attached to a jointed rod and a rotating crank. The 
servo motor powers the mechanism driving the crank to 
rotate. This causes the piston to move back and forth smoothly 
through the 3D printed piston guide. As the piston gets pulled 
back from the guided piston holes, it creates a spacing large 
enough for the payload to be released.

V. TESTING AND EVALUATION 
A. Concept of Operation 
Fig. 21 shows the concept of operation. As seen, the search 
vehicle navigates into the area of interest and thoroughly 
scans the areas for victims. While scanning, the vehicles also 
maps the environment, and localizes itself within the map. 
The created map is saved on the memory of the onboard 
computer. Once a victim is identified, the vehicle returns 
autonomously to where it was launched from using the map 
that was generated and saved. The search vehicle shares the 
generated map with the rescue vehicle, which carries a rescue 
package to be delivered autonomously to the identified 
victim. The rescue vehicle uses the map created by the search 
vehicle to autonomously navigate the environment. Once the 
rescue package is delivered, the rescue vehicle flies back to 
the launch point to complete the mission.  
 
Figure 21. Concept of operations.

VI. CONCLUSION  
This paper presented collaboration between two UAVs for 
search and rescue missions in GPS-denied environments 
including indoor environments. Both the search and rescue 
vehicles have been built using commercial off-the-shelf 
components for the project. Instead of using prebuilt 
multicopters, we selected different parts for and built the 
UAVs from scratch to meet the objectives of the project that 
would enable the navigation of the UAVs in both outdoor and 
congested indoor environments. The developed SLAM and 
target recognition algorithms have been tested successfully 
for various lighting conditions. The flight test of the search 
and rescue UAVs have also been successfully completed. 
Ground and simulation test results showed satisfactory 
tracking of the vehicles in the absence of GPS.
