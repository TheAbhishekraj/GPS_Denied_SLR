Abstract—This paper presents a fully autonomous and low-
cost quadrotor helicopter system in GPS-denied environments.
An extended Kalman ﬁlter (EKF) framework is employed to
fuse the raw data from inertial measurement unit (IMU), optical
ﬂow, ultrasonic rangeﬁnder to achieve real-time state estimation
of the quadrotor. An improved cascaded proportional-integral-
derivative (PID) control scheme is proposed to achieve high-
precision ﬂight control for the quadrotor. A lightweight, powerful
app of DroneKit-Python is integrated to directly guide the ﬂight
mission of the quadrotor on an onboard computer. The onboard
computer which communicates with the ﬂight controller using the
MAVLink protocol augments the performance of the autopilot by
a low-latency link. Finally, the autonomous quadrotor system is
justiﬁed by real-world experiments, and the experimental results
show that the quadrotor can realize high-precision autonomous
localization in an indoor environment.
Index Terms—quadrotor helicopter, multi-sensor fusion, ex-
tended Kalman ﬁlter, cascaded control
I. INTRODUCTION
Nowadays, quadrotor helicopters are mainly used in open
outdoor areas based on airborne GPS receiver. However, GPS
signals are often weak or even unavailable in many mission
scenarios [1], such as search and rescue, monitoring and
tracking, intelligent transportation, etc. Because this traditional
positioning technology cannot meet the realistic needs, the
quadrotor is acquired to sense the surrounding environment
autonomously using onboard sensors. It is essential that the
quadrotor is capable of achieving high-precision state esti-
mation and autonomous ﬂight control. Therefore, autonomous
positioning method based on onboard sensors in GPS-denied
environments has become a hot topic in academic research
and practical application. Multi-sensor fusion techonlogy is
often used in environmental perception, state estimation and
prediction. Usually, single sensor has limitations in obtaining
accurate state information. The inertial measurement unit

There are some recent papers focus on multi-sensor fusion
for autonomous ﬂight of quadrotors. Most works [2]–[4]
realize autonomous localization mainly based on GPS receiver
in outdoor scenarios, and the localization problems in some
complex and closed environments are not considered. To
address the pose estimation problem in an indoor environment,
an extended Kalman ﬁlter (EKF) for pose fusion based on 3D

a reliable and complete system that integrates a camera and a
low-cost IMU to achieve high-precision localization for differ-
ent applications. An improved method which integrates IMU
data and visual information is proposed to realize accurate
and robust motion estimation for a quadrotor by simulation
and real experiments [7].
In this paper, we present a fully autonomous, low-cost,
and high-accuracy quadrotor system with multiple sensors
to perform ﬂight missions in GPS-denied environments. A
navigation scheme based on multi-sensor fusion algorithm to
estimate the states of quadrotor is proposed, not depending
on real-time indoor autonomous vehicle test environments,
such as OptiTrack system [8] or UWB system [9]. Different
from the above works, a comprehensive EKF framework with
low-power computing is designed. Compared with the simple
complementary ﬁlter, the EKF [10] has better measurement
error rejection ability and fault tolerance ability by fusing all
available measurements. The overall control structure consists
of a lower ﬂight controller and an upper onboard computer.
An improved cascaded proportional-integral-derivative (PID)
control method is designed with multi-sensor fusion in the
ﬂight controller. A fully customized upper control scheme

III. NAVIGATION ALGORITHM
A single inertial navigation system (INS) will lead to large
navigation errors of the quadrotor. To solve this problem,
multiple sensor data are fused through an EKF algorithm
for precise localization in GPS-denied environments. The
EKF framework which combines various sensor information
together has different operation modes. To obtain a reliable
position and attitude estimation, the raw data of IMU, mag-
netometer, barometer, ultrasonic rangeﬁnder, PX4FLOW and
airspeed meter are used to accomplish the multi-sensor fusion.
The estimation process is shown in Fig. 2.
Fig. 2. Estimation process of EKF algorithm.
The minimum set of sensors for the EKF framework consists
of IMU, magnetometer and barometer. The magnetometer
assists the IMU to achieve pose estimation, and the barometer
assists the ultrasonic rangeﬁnder to achieve altitude estimation.
Ultrasonic rangeﬁnder and optical ﬂow are mainly used for
localization of the quadrotor. The EKF algorithm uses a total
of 24 state variables, which can be described as

IV. INDOOR FLIGHT EXPERIMENTS
As shown in Fig. 3, a fully customized quadrotor helicopter
system is built to justify the navigation algorithm and au-
tonomous ﬂight control design. Low-cost sensors are selected
to achieve high-precision autonomous positioning tasks in an
indoor environment.
A. Hardware Architecture
The hardware architecture is composed of a quadrotor
frame, DC brushless motors, electronic speed controllers,
Fig. 3. Quadrotor helicopter system.
power system, ﬂight control system, and wireless modules.
The ﬂight control system which consists of Pixhawk 2.4.8
autopilot and Raspberry Pi computer is divided into a lower-
level ﬂight controller and an upper-level task scheduler. The
autopilot can be connected to the onboard computer via USB
to TTL module. The onboard sensors of PX4FLOW and
ultrasonic rangeﬁnder are installed under the quadrotor to
accomplish the positioning task. The wireless modules connect
the ﬂight control system with the ground control station (GCS)
to achieve data transmission. The hardware architecture of the
quadrotor system is shown in Fig. 4.
Fig. 4. Hardware architecture of the quadrotor system.
B. Software Architecture
An embedded software system is built in the onboard com-
puter to enhance autonomy of the quadrotor. The software sys-
tem is based on an Ubuntu system, which integrates DroneKit-
Python to control the quadrotor based on scripts. DroneKit-
Python is a powerful app that provides programmatic access to
the state information of the quadrotor. The onboard computer
communicates with the ﬂight controller via the MAVLink
protocol. If the GCS and the onboard computer are on the
same LAN, we can use GCS to remotely login the IP address
of the onboard computer via Secure Shell.

C. Experimental Results
The process of safety check, unlocking, take-off, hovering,
and landing is accomplished autonomously by the ﬂight con-
trol system in an indoor environment. Hovering state of this
test lasts for about one minute. As can be seen in Fig. 5, the
horizontal position errors are mostly within ±0.2 m according
to the scatter ﬁgure and histogram. The altitude and attitude
trajectories of the quadrotor are shown in Fig. 6, it can be seen
that the altitude error is within ±0.05 m, whereas the desired
altitude is 0.5 m during the hovering. The four normalized
control inputs are shown in Fig. 7, it can be seen that they are
all with some reasonable values.
V. CONCLUSIONS
This paper presents an efﬁcient sensor combination scheme
to fuse multiple data based on EKF framework for accurate
localization of the quadrotor in GPS-denied environments.
An improved cascaded PID controller is adopted to achieve
the ﬂight control, and the whole process of the autonomous
ﬂight task is accomplished by the ﬂight control system. The
indoor ﬂight experiments verify the superior performance of
the proposed navigation and control algorithms.
