# 05_papers_fulltext — Full-Text PDF Corpus

This directory holds the **288 full-text research paper PDFs** collected for the systematic literature review:  
**"GPS-Denied Navigation for UAVs: A Systematic Literature Review of Multi-Sensor Fusion Approaches (2010–2026)"**.

---

## 1. Corpus Summary

* **Total PDF Files:** **288** (`REC_0001.pdf` to `REC_1678.pdf`)
* **Total Directory Size:** **~1.50 GB** (1,610,845,958 bytes)
* **Naming Convention:** `REC_XXXX.pdf` matching the canonical Paper ID.
* **Corpus Correspondence:**
  * **279 In-Corpus Papers:** Formally included in the synthesis corpus (`02_data_processed/MASTER_EVIDENCE.csv`).
  * **9 Out-of-Corpus / Deferred Papers:** 3 screening-excluded papers + 6 deferred papers retained for audit traceability.
  * Exactly matches the 288 extraction markdown files in [`_MANUAL/abhishek/per_paper/`](file:///e:/GPS_Denied_SLR/_MANUAL/abhishek/per_paper/) and [`03_extraction/per_paper/`](file:///e:/GPS_Denied_SLR/03_extraction/per_paper/).

---

## 2. Governance Note
Per `.gitignore`, individual `.pdf` binaries are excluded from Git version control to prevent repository bloat, while this repository manifest tracks their status. All PDFs are permanently preserved on local disk.
