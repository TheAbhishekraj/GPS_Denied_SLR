TITLE: Unified Voxel-Centric LiDAR-Visual-Inertial SLAM for Large-Scale GNSS-Denied Environments
AUTHORS: Cao Y.; Zhang C.; He X.; He P.; Wang T.; Chen Y.
YEAR: 2025.0
ABSTRACT: Large-scale SLAM in GNSS-denied environments requires unified architectures integrating odometry estimation and loop closure detection while managing computational complexity. We present an adaptive voxel-centric SLAM framework employing a Hash-Octree structure for multi-modal information organization. The system extends single-camera voxel mapping to multi-camera configurations through multi-camera patch propagation. Each voxel maintains geometric plane parameters from LiDAR and multi-camera visual observations with temporal metadata. The Error-State Iterated Kalman Filter (ESIKF) tightly couples point-to-plane LiDAR constraints with multi-camera photometric residuals. Dual point cloud accumulators construct rotation-invariant descriptors in polar coordinates for efficient loop closure detection. Comprehensive evaluation demonstrates superior performance in kilometer-scale environments. © 2025 IEEE.
