TITLE: Autonomous UAV navigation in GPS denied environments using Lidar Point Clouds
AUTHORS: Briggs M.M.; Castano L.M.; Morgan E.
YEAR: 2023.0
ABSTRACT: This work describes an algorithm for GPS denied navigation which uses AI-based pattern matching with Feature-Augmented Terrain Referenced Navigation. sUAS-borne radial-scan LiDAR can be used to generate a local high-spatial-resolution point-cloud (LPC) elevation map. This map is then used for onboard/real-time registration to a hybrid elevation map, that integrates high- resolution feature point clouds with lower-resolution terrain elevation maps. This enables geographic location and altitude of the sUAS as measurements for the navigation filter. GPS denied features are then incorporated into autonomous navigation framework. © 2023, American Institute of Aeronautics and Astronautics Inc, AIAA. All rights reserved.
