Abstract— This paper describes a multi-robot coordinated 
heterogeneous vehicle which employs cooperative unmanned 
ground vehicles (UGVs) and unmanned aerial vehicles (UAVs) 
to explore and map a GPS-denied unknown terrain. Exploration 
processes like cave exploration, tunnel inspections required an 
accurate and quick mapping of the environment in emergencies 
for rescue or maintenance operations. This multi-robot system's 
main objective is to use the Dijkstra algorithm to produce a 2D 
and 3D map of an unexplored region. Each robot features a 
border identification system that uses image processing to 
derive border locations. The autonomous exploration problem 
is a partially observable Markov decision process (POMDP) to 
the local planner exploration component. The robot is directed 
to the uncharted region in the map after recovering boundary 
points in the region separating known from unknown space. The 
global planner graph, introducing flexible values, is constructed 
during the discovery phase to examine the robot's border 
positions at the end. The two methodologies are combined with 
speeding up the search for border sites. Closed-loop control 
ensures that the robot is always pushed to its greatest advantage 
following achieving the desired advantages. Finally, the 2D and 
3D maps obtained from each robot are combined using 
conventional map merging techniques to form a map. 
Keywords— Autonomous Exploration, Path planning, Dijkstra 
algorithm, Collaborative system, heterogeneous vehicular 
system. 
I. INTRODUCTION 
Autonomous robots such as unmanned ground vehicles 
(UGVs) and unmanned aerial vehicles (UAVs) are becoming 
a new adoption in various fields of real-world applications. 
The primary reason behind this faster implementation of such 
autonomous robots in applications is their ability to move 
around an unknown complex environment. It can be able to 
execute the desired task without any human hindrance. Many 
existing robots need a well-developed environment model to 
move around and accomplish the desired task. Without these 
predefined navigation models, the robots are equipped with a 
GPS-based external environment map. In this work, we focus 
on developing an autonomous exploration of a coordinated 
robot system in an entirely GPS-denied, wholly unknown 
environment 
and

Some existing exploration robots require a piece of partial 
information about the environment to plan their path [1]-[4]. 
But those frameworks fail in a completely unknown 
environment. To avoid this, existing systems use an active 
SLAM strategy that does not require any information about 
the environment to plan the robot path [5]-[7]. However, the 
framework is limited to specific applications as this technique 
drives the robots to acquire the possible knowledge of the 
entire environment, which the existing system does not 
require. Therefore, a combination of suitable exploration and 
various applications uses multiple robots to carry out the 
desired task cooperatively [8]-[12].

Implementing collaborative tasks enables the multi-robot 
system to share the information between the robots in the 
system, thus decomposing the entire environment exploration 
and mapping efforts between the individual robots. The 
distribution of the effort between the robots in the system 
increases the overall speed of operation by increasing the 
number of robots in the system and flexibility, enabling the 
system to reach more complex parts of the environment and 
map it. Generally, UAVs have lesser endurance in their flight 
time, which affects the entire system's operational time. The 
distributed load can reduce the UAVs' load, increasing the 
system operation time. Applications like search and rescue 
operations, automated inventory management, and tunnel 
surface inspection activities where the human presence 
cannot 
require 
immediate 
action 
under 
emergency 
conditions. Multi-robot systems enhance the desired 
objective of exploring and mapping the unknown 
environment more quickly than the single robot's work time.

mapping system using 5 UGVs and 4 UAVs in heterogeneous 
teams. A heterogeneous vehicular system is approached to 
overcome constraints likeability to map a vast volume of 
environment. The proposed system follows the leader-
follower technique to plan the navigation of the entire system 
using frontier points. The leader UGV is placed at the centre 
of the square, wherein the four followers UGVs are placed at

III. SYSTEM WORKFLOW AND ALGORITHM 
      In an unknown environment exploration system, the 
system should begin by autonomously exploring and 
mapping the environment to determine how to begin its 
operation. In a SLAM approach, autonomous exploration and 
map creation are usually two separate processes. During the 
movement, the Frontier-Based method for autonomous 
exploration algorithm calculates the system's goal position. 
In contrast, the Gmapping algorithm creates the 2D 
occupancy map using the information from the LIDAR 
scanned data. This process continues, and the map is updated 
regularly when the robot reaches an unknown area. The 
system workflow is shown in Fig.2. 
      After obtaining the map, the Dijkstra path planning 
algorithm uses the generated map as input to execute global 
path planning. The DWA planner will avoid environmental 
obstacles by using the laser scan data acquired from the 
LIDAR sensor. The system will plan a collision-free shortest 
path to the target point by combining these two path planners. 
 
Fig.2. System workflow for unknown map 
 
A. Global Path Planning Algorithm 
      The grid-based map is used in this work to process the 
completely unknown environment. The entire environment is 
divided into identical uniform cells in a grid-based map. Each 
cell in the environment is assigned a value based on the 
likelihood of encountering an obstacle. This type of grid-based 
map isn't suitable for large environments. To overcome this, a 
suitable algorithm for global path planning should be chosen, 
which should be more efficient in terms of timeliness and 
return the shortest path. 
      The Dijkstra algorithm is a popular single-source path 
planning method that finds the shortest path between the start 
and goal nodes. Using the weights of the edges, the Dijkstra 
algorithm produces the shortest path between the source and 
target nodes. Breadth-first Search (BFS) can compute the cost 
of any given node to the target node. BFS involves selecting 
the nearest node to the target node instead of the closest node 
to the source node. Dijkstra algorithm centres the source node 
and extends outwards until the target node is reached. 
Therefore, the Dijkstra algorithm is chosen as the system's 
global path-planning method. 
B. Local Path Planning Algorithm 
      Obstacle avoidance is major consideration which the 
multi-robot system should consider. The Dynamic Window 
Approach (DWA) obtains the global plan and cost map and 
then produces suitable velocity instructions for the system to 
navigate around environmental obstacles. DWA creates a 
velocity vector space that includes the system's translational 
and rotational velocities. A set of speeds is created and 
simulated in that particular instant based on the input. The 
system drivers pick and process the optimal velocity after the 
results are assessed from numerous sets. 
C. Autonomous Exploration 
      An autonomous exploration system's major task is 
navigating the system in a completely unknown environment. 
The system should navigate from an unoccupied region into 
an unknown area rather than navigating again in the explored 
area. The edge grid is the empty grid that exists next to any 
unknown grid. The system should navigate to the edge grid,

[p.4]
expanding the exploration range and building a map of the 
unknown region. 
      The tasks in autonomous exploration may be divided into 
two parts. 
1. Edge Detection: The edge between the open and unknown 
regions is determined through edge detection. The region is 
deemed accessible if the length of the detected edge exceeds 
the size of the system footprint, else the edge is considered 
inaccessible. 
2. Target Point Generation and Navigation: Once an available 
path has been discovered using edge detection, the system 
must now build a path from its present state to the target 
region. At the same time, the system should figure out the 
shortest route between its present location and the accessible 
target area. It is a single source with multiple target scenarios. 
We employ the Dijkstra method to determine the shortest path 
between the present point and the target region. When the 
system reaches the target location using the shortest path 
created by the Dijkstra algorithm, it adds that point to the list 
of covered edges, which allows the system to go to new 
unexplored areas rather than mapping the same region again 
and over. 
D. Mapping 
      Gmapping is used to create 2D occupancy grid maps from 
LIDAR scan data in this study. The two most prevalent 
algorithms for SLAM and map generation are Gmapping and 
Hector slam. Gmapping employs both LIDAR data and 
odometry values, and it outperforms the Hector SLAM, which 
solely uses laser scan data. Our suggested system comprises 
one leader ground robot and four follower ground robots. Each 
of the four following ground robots has a LIDAR sensor that 
produces LIDAR scan data and local maps. Local maps from 
each robot are sent to the ROS nodes using the conventional 
map merging approach; a centralised map is created from the 
input. The multirobot_map_merge package influenced the 
map merging package used in the system. Our package carries 
the map merging procedure online between the follower 
ground robots. 
IV. SIMULATION AND RESULT 
      This proposed system is developed and simulated in ROS 
– Gazebo environment. In this article, the NEXUS Omni 4 - 
Wheeled Mecanum robot is utilised for ground robots, while 
the Hector Quadrotor is used for aerial robots. All following 
ground robots include a LIDAR sensor, which is used to create 
LIDAR scan data, and each aerial robot has a Kinect camera 
fitted for producing point cloud data. 
      The leader ground robot is in charge of avoiding obstacles 
in the environment and planning the system's path. The 
follower rovers are designed to follow the leader ground robot 
over a 2-meter distance, forming a square with the leader robot 
in the middle. A quadrotor with a 2-meter offset above each 
follower ground robot follows it. The 8-follower robots form 
a cube configuration with a 2-meters side. 
A. Autonomous exploration test 
      The multi-robot system produces a goal point to advance 
the system to the undiscovered area based on the frontier 
points created. The map created by the system is displayed in 
the figure after a 20-second interval. The white region on the 
environment represents the explored area of the provided 
environment. The red arrow in the figure shows the target 
position of the system at that time. The target position of the 
leader robot is provided by the path planner, and the 
formation control is deployed by an external python script. 
B. Indoor Navigation  test 
      The Navigation stack is responsible for creating the 
frontier points in the unexplored area. The green curve in 
figure 4 shows the global path, and the small red curve denotes 
the local path of the system. Figure 4 depicts the system with 
obstacles on its way. The system successfully replans its path 
and avoids obstacles while calculating the shortest path to the 
current destination point. When a local deadlock occurs, the 
system spins clockwise to re-establish a suitable path for 
subsequent navigation. This procedure is repeated when the 
system reaches the target point, and a new set of frontier points 
is produced to navigate further. The system will not create 
frontier points if the whole area has been explored, and the 
search will be terminated.

C. Mapping 
 
The ROS native gmapping package maps the unknown 
environment in this proposed system. As a ROS node, this 
module offers laser-based SLAM. The 2D occupancy grid 
map is created using laser input. Each follower ground robot 
in the system is equipped with a laser sensor that generates a 
2D occupancy map and combines it with the others in real time 
to map the unknown environment faster. Each quadrotor in the 
system has a stereo camera mounted at a 45-degree angle to 
cover the surrounding region effectively. The point cloud data 
of the environment is produced using the data from the stereo 
camera. Offline, using an external processor, this point cloud 
data are processed and combined to create a full 3d map of the 
unknown area.

V. CONCLUSION 
 
This paper offers a new method of integrating ground and 
aerial robots to tap a completely unknown area faster, 
including detecting obstacles in the environment, identifying 
appropriate places for the system to travel without clashing 
with the obstacles, and route planning and mapping of the 
environment. It is also observed that the distribution of load 
among the robots improvise the system and mapping 
efficiency.  
 
The planner of the envisioned system has a maximum 
velocity along x and y to be 1.5 m/s and 1.3 m/s, respectively, 
and a minimum velocity along x and y to be 1.1 and 1.05, 
respectively. The angular velocity maximum and minimum 
are set to be 1.82 rad/s and 0.9 rad/s, respectively. The 
proposed system is mapped using a combination of robot 
composition and the envisioned system. The results of that are 
shown in table II.
