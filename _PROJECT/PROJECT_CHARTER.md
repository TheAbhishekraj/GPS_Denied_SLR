# Project Charter — GPS_Denied_SLR

## Purpose
Complete a PRISMA 2020 systematic literature review on GPS-denied
UAV navigation. Produce a verification-grade evidence base.
Submit a manuscript to IEEE T-RO or IEEE Access.

## Scope
- Corpus: 285 INCLUDE papers (from 291 full-text assessed)
- Evidence: per-paper extraction with quote-anchored metrics
- Deliverables: manuscript, supplementary tables, PRISMA flow,
  audit trail

## Constraints
- No fabricated data.
- Every count traceable to a file.
- Every metric traceable to a quote + page in the source PDF.
- Every decision reversible via quarantine.
- No write without approval on frozen files.

## Success criteria
1. Anchor frozen and hash-recorded.
2. All 285 papers extracted with quote-anchored evidence.
3. Manuscript drafted with every number traced.
4. Zero forbidden legacy numbers in any deliverable.
5. Full PRISMA 2020 audit trail.
6. Manuscript submission-ready.

## Out of scope
- New corpora beyond 285.
- Modifying raw exports.
- Changing inclusion criteria mid-project.
