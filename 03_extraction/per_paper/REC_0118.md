## 3. Abstract / TL;DR
Develops and verifies a vision-aided guidance system using air-ground robot cooperation for UAVs in GNSS-denied environments to circumvent payload restrictions on mini UAVs. 

## 4. Environment & Platform
- **Environment:** Indoor Static environment [p.5]
- **Platform:** Parrot AR.Drone2.0 and Turtlebot2 [p.2]

## 5. Navigation/Localisation Method
- **Methodology:** Vision-aided cooperative SLAM system dividing tasks between UGV (modified ORB-SLAM2) and UAV (modified PTAM).
- **Type:** COOPERATIVE

## 6. System Architecture
- **Platform:** Parrot AR + Turtlebot2 [p.2]
- **Sensors:** Monocular camera, IMU, Pressure (UAV); Kinect V2 (UGV) [p.2]
- **Compute:** Lenovo Y410p [p.2]
- **Communication:** Wireless LAN [p.2]

## 7. Experimental Setup

- **environment:** Indoor conditions [p.4]
