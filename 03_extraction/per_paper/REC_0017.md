## 2. Problem Statement
"Localization and navigation in an indoor environment using nano Unmanned Aerial Vehicles (UAV) always pose great challenges. Since Global Navigation Satellite System (GNSS) reference is unavailable, the UAV has to rely on its own onboard or external sensors to navigate." [p.1]

## 3. Motivation
"Although there are numerous potential applications, getting to understand the structure of the flight platform can be cumbersome and confusing. Packages and resources provided on the Qualcomm developer network (QCN) and their official GitHub group ATLFlight contain un-unified and disorderly chunks of information. In this paper, we present an organized documentation that presents in detail, the platform structure as a whole, from hardware to software architecture, including installation and API related applications." [p.1]

## 5. Proposed Method
Snapdragon Flight Nano UAV Platform with VINS Integration — SYSTEM
"In order to develop a nano UAV in a GPS-denied environment, a visual-inertial system (VINS) consisting of a monocular camera and a low-cost inertial measurement unit (IMU) should be integrated, as they make a minimum, ultra lightweight sensor suite that enables both autonomous flight and sufficient environment awareness." [p.1]
The paper presents a complete platform documentation and integration guide for the Qualcomm Snapdragon Flight board, including hardware setup, software architecture, VIO (Visual-Inertial Odometry) configuration using ROVIO/OKVIS, and flight controller integration for autonomous GPS-denied navigation. [p.1-6]
## 6. System Architecture
- Platform: Custom nano quadrotor (250mm wheelbase, 200g weight) with Qualcomm Snapdragon Flight board [p.2-3]
- Sensors: Monocular downward-facing camera (OV7251, 640x480@30fps), IMU (ICM-20608, 200Hz), optical flow camera, ultrasonic rangefinder, barometer, magnetometer [p.2-3]
- Compute: Snapdragon Flight (Snapdragon 801, 4x Krait cores @2.26GHz, Hexagon DSP, Adreno 330 GPU) running Linux + DSPAL for VIO on DSP [p.2-3]
- Communication: Wi-Fi/Bluetooth for ground station; UART/I2C/SPI for sensor interfaces; ESCs for motor control [p.3-4]

## 7. Experimental Setup
- real_or_sim: BOTH
- environment: Indoor motion capture arena (Vicon) for validation; simulated Gazebo/ROS environment [p.4-5]
- trials/runs: Multiple flights including hover, figure-8, and spiral trajectories [p.5]
- baselines: Vicon motion capture ground truth; simulation vs. real flight comparison [p.5]
- datasets: Onboard sensor logs (IMU, camera, optical flow); Vicon reference trajectories [p.5]

## 18. Best Combination & Accuracy
### 18.1 Best sensor combination
Monocular camera + IMU (VIO) + Optical flow + Ultrasonic + Barometer (for altitude hold)
### 18.2 Best algorithm
ROVIO / OKVIS (Visual-Inertial Odometry) running on Hexagon DSP via Snapdragon Navigator SDK
### 18.3 Best accuracy (metric + value + unit + [p.N])
Position RMSE ~0.1–0.2 m across hover, figure-8, and spiral trajectories (estimated from Figs. 8–10) [p.5]
### 18.4 Baseline comparison
Vicon motion capture ground truth; simulation vs. real flight shows similar trajectories
### 18.5 Conditions of best accuracy
Indoor Vicon-tracked environment; good lighting for visual features; low-speed maneuvers
### 18.6 Trade-offs
Proprietary SDK (Snapdragon Navigator) limits reproducibility; optical flow/ultrasonic not fused in VIO; limited to indoor/low-altitude operation
### 18.7 Generalization limits
Platform-specific (Snapdragon Flight); proprietary VIO backend; no outdoor/GPS-transition results; nano UAV payload limits sensor options
Documents a complete nano UAV platform integration with Snapdragon Flight for GPS-denied indoor navigation; provides tutorial-style hardware/software guide. [p.1, p.6]
