## 1. Bibliographic Metadata
Y. Zhou, G. Qin, and F. Lin, "Development of Nano UAV Platform for Navigation in GPS-Denied Environment Using Snapdragon," Temasek Laboratories, National University of Singapore, 2018.

## 2. Problem Statement
"Localization and navigation in an indoor environment using nano Unmanned Aerial Vehicles (UAV) always pose great challenges. Since Global Navigation Satellite System (GNSS) reference is unavailable, the UAV has to rely on its own onboard or external sensors to navigate." [p.1].

## 3. Motivation
"Although there are numerous potential applications, getting to understand the structure of the flight platform can be cumbersome and confusing. Packages and resources provided on the Qualcomm developer network (QCN) and their official GitHub group ATLFlight contain un-unified and disorderly chunks of information. In this paper, we present an organized documentation that presents in detail, the platform structure as a whole, from hardware to software architecture, including installation and API related applications." [p.1].

## 4. GPS-Denied Context
INDOOR
"Therefore, in order to develop a nano UAV to work in a GPS-denied environment, we focus on the platform with VINS integration, as well as high computation power and low power consumption." [p.1].

## 5. Proposed Method
Method name: Nano UAV platform with VINS on Snapdragon Flight
Category: VIO
"a visual-inertial system (VINS) consisting of a monocular camera and a low-cost inertial measurement unit (IMU) should be integrated, as they make a minimum, ultra lightweight sensor suite that enables both autonomous flight and sufficient environment awareness" [p.1].

## 6. System Architecture
- Platform: "we have decided to use the highly-integrated Snapdragon Flight controller board as our autopilot" [p.1]
- Sensors: "It also integrates most of the necessary sensors, which includes a barometric pressure sensor, GNSS, 9-Axis IMU Sensor, downward optical flow camera with resolution of 640480 and a 4K high resolution front camera." [p.2]
- Compute: "The flight controller is running on the DSP of Qualcomm Snapdragon 801 processor, which can make sure the real-time property. The CPU and GPU are used to run Linaro system, robot operating system (ROS) and high level algorithms." [p.3]
- Communication: "The board can either be wired accessed via serial port and USB, or remotely accessed via Bluetooth 4.0 and 2.4G/5.8G WIFI connection." [p.2]
