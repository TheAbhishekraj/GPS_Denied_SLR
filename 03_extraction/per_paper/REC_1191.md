## 2. Problem Statement
"This paper addresses the problem of position estimation in UAVs operating in a cluttered environment where GPS information is unavailable." [p.1]

## 3. Motivation
"However, in cluttered environments like forests and indoor environments, there is an intermittent loss of GPS (sometimes no GPS signal), which can lead to inaccurate position estimates, rendering the UAV unstable." [p.1]

## 4. GPS-Denied Context
MIXED
"GPS-denied operation" [p.1]

## 5. Proposed Method
Method name: SN-MNN (Spectrally Normalized Memory Neuron Network)
Category: OTHER
"A learning-based approach is proposed that takes in the rotor RPMs and past state as input and predicts the one-step-ahead position of the UAV using a novel spectral-normalized memory neural network (SN-MNN)." [p.1]
