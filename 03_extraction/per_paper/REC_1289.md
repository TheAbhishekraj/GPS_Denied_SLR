## 2. Problem Statement
"With the continuous expansion of the application field of UAV intelligent systems to GNSS-denied environments, the existing navigation system can hardly meet low cost, high precision, and high robustness in such conditions. Most navigation systems used in GNSS-denied environments give up the connection between the map frame and the actual world frame, making them impossible to apply in practice." [p.1]

## 3. Motivation
"Therefore, this paper proposes a Lidar navigation system based on global ArUco, which is widely used in large-scale known GNSS-denied scenarios for UAVs." [p.1]

## 4. GPS-Denied Context
INDOOR
"The navigation system has been tested in the dry coal shed of a thermal power plant using a UAV platform. Experiments demonstrate that the system can achieve global, accurate, and robust pose estimation in large-scale, complex GNSS-denied environments." [p.1]

## 5. Proposed Method
Method name: Global ArUco-based Lidar navigation system
Category: HYBRID
The system jointly optimizes Lidar, IMU, and global ArUco information by factor graph and outputs pose in the real-world frame. It includes a method to update global ArUco confidence with sampling, uses global ArUco to maintain navigation when Lidar is degraded, and has a loop closure determination part based on ArUco.
"this paper proposes a global ArUco-based Lidar navigation system suitable for UAVs in a GNSS-denial environment." [p.3]

## 6. System Architecture
- Platform: DJI Matrice200 RTK unmanned flight platform
- Sensors: Velodyne-16 surround Lidar, MTI-300 inertial measurement unit, ZENMUSE X5S gimbal camera, global ArUco markers
- Compute: Intel NUC8 onboard computer
- Communication: ROS architecture
"The navigation system test uses Velodyne-16 surround Lidar, MTI-300 inertial measurement unit, Intel NUC8 onboard computer, ZENMUSE X5S gimbal camera, and DJI Matrice200 RTK unmanned flight platform." [p.12]
"The algorithm of the navigation system is implemented in C++ and runs on an Ubuntu 18.04 operating system based on ROS architecture." [p.12]
