## 2. Problem Statement
"However, despite this rapid progress, GPS-denied Degraded Visual Environments (DVEs) represent a hard limit for autonomous systems as the sensor information inside them can be severely degraded." [p.1].

## 3. Motivation
"Towards enabling aerial robotic autonomy in a broader set of DVEs, including fog/smoke-filled environments, this work examines the problem of utilizing Infrared (IR) vision that can penetrate, to a certain extent, such degraded conditions" [p.1].

## 5. Proposed Method
Method name: Thermal-inertial localization with ROVIO
Category: HYBRID
"a thermal-inertial sensor fusion approach is proposed that relies on the data extracted from a FLIR Tau 2 Long-Wave IR (LWIR) which are then software time-synchronized with the data from an IMU." [p.1].
