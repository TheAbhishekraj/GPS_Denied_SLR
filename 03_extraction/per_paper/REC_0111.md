## 3. Abstract / TL;DR
Presents a positioning system based on monocular SLAM and IMU data to allow drone operation in GPS-denied environments. Uses semi-direct visual odometry (SVO) with EKF integration to estimate scale factor.

## 4. Environment & Platform
- **Environment:** Outdoor environment (rectangular field) [p.4]
- **Platform:** Hexa-rotor [p.4]

## 5. Navigation/Localisation Method
- **Methodology:** Monocular SLAM + IMU fusion with EKF to estimate scale factor dynamically.
- **Type:** SLAM (Visual-Inertial)

## 6. System Architecture
- **Platform:** Hexa-rotor [p.4]
- **Sensors:** Monocular camera, IMU [p.1]
- **Compute:** Upboard processor, custom autopilot board [p.4]

## 10. Stated Limitations
Vertical position estimation of monocular SLAM has large drift [p.3]; poor performance in high-velocity movements [p.4].
